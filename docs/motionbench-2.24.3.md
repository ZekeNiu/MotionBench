# MotionBench 2.24.3：完整纵向报告

在报告首页选择同一运动员的多条测试记录即可比较；选择一条时仍显示个人报告。

纵向测试模块统一采用上图下表，结果表使用完整宽度。速度与储备按实际指标并排绘图；日期较多时，PDF按相同坐标范围分段。每个模块只保留一个“展开所有原始试次数据”入口，展开后可查看各日期、各项目的全部试次。筛查首页保留部位雷达，不再另列“各区域筛查等级”。

等长力量分开显示力量结果、双侧差异和关节平衡。各日期结果沿用个人报告的评价底色、短标签及依据；无标准或缺测继续保留相应说明。能力结构卡按日期数量紧凑排布：两期两列、三期三列、四期两列两行，窄窗口自动换行。

乳酸、CPET、跳跃FVP（SJ／CMJ）、冲刺FVP和相应弹性框架保留原参数、组成值、判定、目标、代表负荷点、模型条件与方法说明。比较图叠加日期系列，非重复的原分析按期显示。弹性框架使用相应FVP数据计算，无需另建测试项目。

本机已有的“示例运动员｜纵向比较（合成）”可在运动员选择框搜索“示例运动员”找到，四期记录为2026-09-01、09-15、09-29和10-13。已通过现有表单为这四条记录补充乳酸、CPET、SJ／CMJ跳跃FVP和冲刺FVP的合成测量，弹性分析由相应数据计算；原有十项测试和人工解读正文保留。补录后旧正文提示复核，保存、重开和原快捷方式显示均已核验。

这组四期示例属于本机资料库。公开安装包不包含本机运动员、测量或正文资料，在新环境安装不会自动出现这组示例。
