# MotionBench 2.27.0 使用说明

2.27.0 统一管理、录入和设置页面的文字层级与间距，并支持分段合计和变向赤字计算。

## 操作界面

正文采用一致的深灰文字。项目说明按规则分段，参数标题与下方内容之间保留明确间距。操作入口、选中状态和提示仍使用各自的颜色。

## 测量方法

创建或编辑项目时，不再要求维护测量方法版本或勾选方法改变。已有动作说明和协议、设备文字仍可记录，但不作为版本匹配条件。使用者负责确认前后测量方法的可比性；不同单位、侧别和结果定义仍分别处理。

## 分段合计

计时项目可以把多个原始分段定义为一个自动合计指标。只填写原始分段，总时间自动计算。每次完整试次先计算总时间，再按项目设定选择代表试次；其他指标随同一试次展示。均值使用相同的完整有效试次集合。

未填写的分段保持为空，不按零处理。原始数据保留，缺少分段时不生成完整总时间。

## 变向赤字

变向计时项目可以配置只读的变向赤字，并在测试方案中指定对应直线计时指标。每次测试自动带入所选方案的参照设置。

变向赤字以秒表示，为本次变向代表时间减去同距离直线代表时间。计算使用同一运动员、同次测试记录中的结果，不从其他日期寻找成绩，也不根据最大速度或模型结果推算。

缺少参照时，原始变向成绩仍保留，赤字显示缺失原因。零值和负值保留；负值提示核对输入。T形任务的差值还包括侧移、返回等移动方式的额外耗时，不能解释为纯转身时间。

赤字在原变向项目中展示。个人报告桌面采用左图右表，横向和纵向比较采用上图下表。图固定展示赤字，结果表同时保留变向时间、直线参照时间和赤字。群体结果先逐人计算，再汇总具备有效配对数据的结果。

本版本不因启用计算指标而自动加入评价阈值、能力评分或队内排名。
