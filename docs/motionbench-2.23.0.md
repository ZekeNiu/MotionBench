# MotionBench 2.23.0 团队报告与纵向比较

在报告首页选择队伍，再多选队员和测试日期。单人单次仍显示个人报告；多名队员同日显示团队报告；多个日期显示个人或团队纵向比较。同一队员同日有多条记录时，在测试记录选择区指定采用哪条。

比较区使用上图下表，可选择指标、突出队员、切换原图对照与日期趋势，以及汇总和个人明细。点击明细中的编辑记录，返回后继续原比较。IMTP保留毫秒坐标，FVP保留物理坐标；各人的结果先独立计算，再汇总均值与样本标准差。

团队纵向逐指标使用所有所选日期都有效且测量口径一致的同一批队员，最早日期为基线。表格显示配对人数、原单位变化、变化的95% CI、Cohen’s dz及Holm校正p。95% CI是单项区间；校正后的p用于多重比较。个人趋势按真实时间间隔展示，序数及疼痛结果按原分、分布和状态转移展示。

快速摘要显示末次状态及相对基线的变化。团队损伤风险筛查用一张身体部位雷达图展示各队员：当前绿色判定对应3分、黄色2分、红色1分，未判定留空；每名队员一条线，点击图例突出队员，点击数据点查看原项目。默认显示末次测试，多日期时可在图内切换日期。训练方向先逐人判断，再显示方向分组和名单。独立解读可手动编辑、生成离线摘要或调用已有AI服务。修改数据后保留正文并提示复核。

PDF跟随当前图表、表格页签和展开状态。HTML和JSON保存完整所选原始记录、评价依据、图表偏好、正文和统计结果；HTML可独立打开继续切换及编辑比较正文。完整JSONL备份同时保留独立比较报告。

资料库中的“模拟队伍·团队与纵向示例”包含24人、6个不等间隔日期，覆盖复杂曲线、缺测、同日重测和不同轨迹。其评价方案和数据均明确标为模拟。

统计依据：[NIST配对分析](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)、[Lakens效果量方法](https://pmc.ncbi.nlm.nih.gov/articles/PMC3840331/)、[R Holm校正](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)。
