# MotionBench 2.27.0 构建验收

本记录对应 MotionBench 2.27.0 / 2.27.0-desktop.1，验收使用合成资料。

通过的回归与核验：

- 完整单元回归 83 套，收据记录 1,228 项检查；桌面单元回归 5 套。各套退出码均为 0，测试输入哈希保持一致。
- Chrome、Edge 共 6 套浏览器检查，合计 66 项；覆盖管理详情、方案编辑、录入、创建、设置及弹窗，包含 1440、1024、390 像素宽度与旧版外观对照。
- 两浏览器分别实际导出个人、横向、纵向 PDF，共 6 份、24 页；渲染页逐页核对，并复核 COD 重点截图。102 个浏览器证据文件的 SHA256 全部匹配。
- Windows 打包程序通过 16 项运行检查；桌面包核验 271 个运行资源，并核对安装包、便携包及更新元数据。

本次通用改动包括取消测量方法版本限制，统一操作界面的文字和间距，以及分段求和、COD差值与测试方案来源绑定。计算结果在录入界面只读，Excel模板保留原始输入。个人桌面报告保持左图右表，COD横向、纵向与仅群体报告保持上图下表；零值、负值、缺参照和其他既有指标通过验证。
