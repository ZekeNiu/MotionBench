# MotionBench 2.18.0-local 审查结论

**结论：本次批准范围已实现并通过最终候选文件的验收。置信度：高。** 数值、交互、数据往返及屏幕/PDF 展示的证据绑定于 [验收记录](acceptance-2.18.0-local.json)；这里的通过不扩展为真实训练干预、设备精度或所有历史测试脚本均通过。

## 原因与修正

| 已确认问题 | 本次修正与核验 |
| --- | --- |
| 四卡与参数分属两侧，形成独立板块 | 四卡合入能力结构分析；参数各自折叠，切换依据仍保留完整参数；桌面两列、手机单列 |
| 卡片与图位的 SJ/CMJ 回退不一致 | 共用协议解析，保留显式选择；未选择时优先有效协议。显式选择无效协议不被悄然替换 |
| 单次无效蹬伸距离被通用值替换显示 | 原始表如实显示输入；空值才标示采用通用距离 |
| 空情景沿用旧结果，视图切换丢失草稿 | 空情景保持字段错误；草稿按记录与协议隔离，保存设置保留上次有效值；无效预览明确不可计算 |
| 输入失焦刷新导致接下来的首次点击失效 | 保存数据时保留控件节点；鼠标交互完成后再更新布局；实际点击序列验证 |
| 切换记录时迟到的失焦事件误写另一记录 | 控件绑定记录 ID；切换前提交当前有效编辑，忽略脱离当前记录的事件 |
| 导出等待保存时内容与点击时设置不一致 | JSON/HTML/PDF 固定开始导出时的快照，保存成功后下载；错误草稿阻止导出并定位 |
| PDF 将关闭的卡片参数全部打印 | 打印重建保留四卡展开状态；关闭参数先移除，展开表格支持续页与重复表头 |

核心跳跃 FVP、90°/30° 最优剖面、参数换算及冲刺 FVP/2022 最优剖面保留。本次没有证据支持将这些公式替换为另一套模型。新增冲刺弹性是独立计算模块，沿用原有 F₀、V₀、身体与环境输入。

## 计算与来源审查

冲刺论文全文、数学附件、作者公开计算器与闭式位移方程已核对。含空气阻力采用作者单端正向 1% 方法；无阻力采用解析公式。ER 平衡距离与 EN 谷底分别求解，不互相替代。情景完整重算，跳高提高与用时下降使用各自正确的改善符号。

24 组作者计算器执行值的最大时间差为 1.21215×10⁻⁷ s；60 组独立 RK4 积分条件的最大时间差为 1.21514×10⁻⁸ s。作者短距离积分的误差会被 1% 差分放大，已验证缩小步长后的收敛，没有靠改变扰动算法消除差异。

论文正文的平衡距离示例与定义、方程及作者计算器存在冲突；项目依照方程与独立计算验收。原分段协议说明已纠正，不将软件最低输入数量表述为论文验证的测试协议。详见 [冲刺弹性方法与审查记录](sprint-elasticity-method.md) 和 [既有冲刺 FVP 方法](sprint-fvp-method.md)。

垂直弹性预印本全文仍未完整取得。已核验作者垂直计算器和现有换算，不据此声称全部实验条件、λ 标定及图表均已覆盖。**该论文完整覆盖置信度：中。**

## 最终验收范围

- 48 个单元套件、694 项检查通过，包含 Morin 工作簿公式/缓存、旧卡片数值基线、新弹性数值、数据兼容与真实 XLSX 字节往返。
- Chrome、Edge 各 18 项实际离线流程通过，包含自动保存、首次点击、刷新、跨记录、显式无效协议、输入错误、保存失败、并发导出快照及实际文件下载；浏览器错误和 HTTP(S) 请求均为零。
- 两浏览器分别检查 1440、1280、900、390 宽度。完整区域截图覆盖四卡及两套弹性各两种视图。
- 实际下载 6 份 PDF：各浏览器关闭参数 23 页、部分展开/约束视图 26 页、全部展开/响应视图 28 页，共 154 页。逐页渲染并核对表格与图表完整性；视觉结论及跨浏览器对照单独记录。

既有 `core-browser-tests.cjs` 另行执行产生 12 项失败：脚本要求的侧栏编辑按钮、旧目录入口和旧新建运动员选择器，在本次 2.17.5 基线中已经不存在。基线与当前均使用报告工具栏和管理中心导航，且该次浏览器错误/网络请求为零。因此这份旧脚本记录为**不适配当前导航**，未计入本次通过的 48 个套件或 36 项浏览器流程，也没有被修改为掩盖失败。

本次未进行原生 Excel 打开重算、真实设备测量、物理手机/打印机验证或真实 AI 服务质量测试。AI 的共享数值、协议绑定及显示设置不使解读过期已验证；不扩展为模型文字质量结论。测试采用隔离的合成记录，未读取或迁移真实运动员数据库。
