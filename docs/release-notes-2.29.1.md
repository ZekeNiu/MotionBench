# MotionBench 2.29.1

修复团队横向比较在“查看报告”时误打开“添加群体参照”的问题。队伍内存在不同评价标准时，直接为原队伍选择共同标准；保存、重开继续使用该设置，成员和来源记录保持不变。

团队纵向比较在指标汇总表加入 mini 趋势图，删除逐指标的个人逐日折叠明细。趋势表示各日期有效成员的群体均值；同人配对变化仍单独列出，缺测不补零。

团队横向和纵向比较默认显示成员分组柱图，并可切换群体均值和图表类型。纵向按成员排列，同一日期使用同一颜色；横向各对象按指标数值从高到低排列，同一序位并排显示，各对象使用固定颜色。数值排序不代表评价等级或成绩优劣。成员分布可使用柱图、点图、箱线图和直方图。

报告选择页调整为一致的内容间距、控件尺寸和选项布局，第一步的个人、团队选项等宽排列，窄窗口下自动纵向排列。报告内容和选择规则保持原样。

“数据录入”和“测试报告”的顶部步骤标题支持鼠标和键盘快捷切换，复用原有前后步骤的校验及保存逻辑。进入“核对并查看报告”只切换到核对步骤，仍由原有按钮确认生成报告。

本次仅针对受影响的模型、选择流程、图表、保存重开和导出进行验收；安装前保留本机程序及资料备份。
