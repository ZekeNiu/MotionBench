# MotionBench Windows 桌面版

桌面版通过 Windows 程序或快捷方式启动，自带运行环境。离线录入、计算、图表、Excel 和报告 PDF 可以直接使用。

本说明对应 **2.24.8-desktop.1**，共用工作台版本为 **2.24.8**。原目录升级、原资料保持、重开和系统快捷方式核验已完成，详见 [2.24.8 验收记录](acceptance-2.24.8.md)，功能说明见 [2.24.8](motionbench-2.24.8.md)。

从 [2.24.8 版本页](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.24.8-desktop.1)下载安装版、便携版或离线 HTML。[2.24.7 回退版本](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.24.7-desktop.1)继续保留。

## 安装

发行包适用于 Windows 10 / 11，x64。

| 文件 | 用途 |
| --- | --- |
| [MotionBench-2.24.8-desktop.1-Setup-x64.exe](https://github.com/ZekeNiu/MotionBench/releases/download/v2.24.8-desktop.1/MotionBench-2.24.8-desktop.1-Setup-x64.exe) | 安装程序，升级时沿用原程序目录 |
| [MotionBench-2.24.8-desktop.1-Portable-x64.exe](https://github.com/ZekeNiu/MotionBench/releases/download/v2.24.8-desktop.1/MotionBench-2.24.8-desktop.1-Portable-x64.exe) | 便携程序 |
| [2.24.8 验收记录](acceptance-2.24.8.md) | 成品校验与本轮核验范围 |

本机安装目录为 `D:\Application\Strength&Conditioning\MotionBench`。运行 Setup 时确认这个原目录，完成后核对运动员、测试记录、方案与人工解读，再关闭并重新打开。原目录升级及真实资料检查的完成状态以验收记录为准。

安装版与便携版均把资料保存在当前 Windows 用户的 `%APPDATA%\MotionBench Desktop`，与程序所在目录分开。

从 2.24.5 或更早版本升级时使用 2.24.8 的 Setup。公开发行版可使用“应用设置 → 更新与版本”，或运行公开发行的 Setup。公开发行附件中的 `SHA256SUMS.txt` 和 `build-provenance.json` 分别提供文件校验与构建来源。公开安装包不包含本机运动员、测量或解读正文。

## 纵向比较

在报告首页选择运动员后，打开“测试记录”勾选多期测试。单条显示原报告，多条自动比较；“代表成绩”统一切换最佳值或均值。点击“编辑测试记录”可选择一期编辑并返回比较。每个记录组合分别保存解读，右上角 AI 图标可直接生成可编辑草稿。

每张比较图可独立勾选首页所选日期中的一个或多个，并随比较文档保存。结果表使用统一“变化趋势”，展示全部所选日期，带纵轴刻度和单位；悬停或聚焦查看完整日期、读数和相邻变化。FMS只显示分差，百分数指标显示百分点差；缺测保持断线，不补零。无实际评价依据的数据保留读数，不显示占位评价。

损伤风险筛查使用部位雷达；等长力量保留力量结果、双侧差异和关节平衡分组，以及各期带状态颜色的短标签和评价依据。运动表现概览少于 3 维显示表格，3 维及以上显示雷达。能力结构、乳酸、CPET、SJ／CMJ 跳跃 FVP、冲刺 FVP 和弹性分析按期保留适用的组成值、判定、目标、代表点与方法说明。FMS 图表采用紧凑布局；跳跃及冲刺 FVP、弹性、IMTP 和负荷－速度图恢复适用的显示选项，逐期 FVP 与弹性分析在宽窗口每行两期、窄窗口每行一期。详见 [2.24.8 纵向显示设置](motionbench-2.24.8.md)和 [2.24.0 比较操作](motionbench-2.24.0.md)。

## 设置通用项目报告图表

在“项目与指标库”进入通用项目的“编辑项目设置”，勾选“在报告中显示可视化图”，选择图型、展示指标及顺序，再保存。图样预览使用示例数据，实际报告使用本次测量。

支持横向条形图、纵向柱状图、试次点图、X–Y 散点图、目标对比图和评分雷达图。散点图选择同一项目的两个不同试次指标；评分雷达选择 3–8 项，采用本次评价方案已有的明确评分规则。不同单位的原值分别绘图。

个人报告在左侧展示图表，右侧保留完整结果、评价与适用的重复统计；纵向比较采用上图下表。关闭图表后展示表格。兼容的已有报告同步项目图样；导出的 HTML、JSON、PDF 保留导出时的图样。步骤与数据要求见 [2.22.0 使用说明](motionbench-2.22.0.md)。

## 更新与启动偏好

1. 点击侧栏底部“应用设置”，进入“更新与版本”。帮助菜单的“检查更新”也进入这里。
2. “启动时检查更新”首次默认开启，可关闭。开启后，在资料与草稿恢复完成后检查一次；有新版本时入口显示“新版本”。
3. 点击“检查更新”可以随时手动查询。发现新版本后查看说明，点击“下载更新”。
4. 下载完成后，点击“重启并更新”。程序先完成当前保存，再启动安装并重新打开。若保存、校验或安装启动失败，按此页面提示处理后重试。

升级沿用原安装目录。关闭程序时不会自动安装下载的更新。便携版提供“下载便携版”，退出程序后替换便携程序，资料继续保留。

## 从网页版迁移资料

1. 在原网页的“备份与恢复”导出完整 JSONL 资料库。
2. 打开桌面版，在“备份与恢复”导入这个完整备份，按需要选择替换或合并。
3. 核对运动员、测试记录、队伍、方案和人工解读；关闭并重新打开，确认资料仍在。
4. 从桌面版再导出一份完整备份，作为迁移后的检查副本。

网页版和桌面版分别保存资料。交换资料时使用完整备份，并明确采用哪份资料。“本次测试 HTML / JSON”和 PDF 用于单条报告分享，完整库迁移使用 JSONL。

## AI 连接

在“AI 服务”中填写 HTTPS 地址、密钥和模型并保存。桌面版使用当前 Windows 用户加密保存密钥，重新打开后可继续使用。原网页启动器与桌面版分别保存连接；首次切换时在桌面版重新填写。

密钥与运动员备份分别保存。换电脑或换 Windows 用户后，在“AI 服务”重新配置连接。

## 备份与回退

重要测试批次完成后，在“备份与恢复”导出完整 JSONL。升级、重装和卸载保留桌面资料；主动删除 `%APPDATA%\MotionBench Desktop` 会删除这份本机资料。

返回旧程序前，先另存完整备份。程序版本回退与资料恢复分别进行；网页版回退使用原浏览器入口与相应备份。

本轮上一版的源码、程序和校验文件保留在 [2.24.7 回退版本](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.24.7-desktop.1)，其完成范围见 [2.24.4 验收记录](acceptance-2.24.4.md)。本轮升级前保护与升级结果见 [2.24.8 验收记录](acceptance-2.24.8.md)。

## 开发构建

使用 Node.js 24 和 Python，运行 `npm ci`、`npm run build`、`npm test`、`npm run test:desktop-unit`、`npm run dist:windows` 和 `npm run verify:desktop-package`。Windows 产物位于 `dist-desktop`。版本及依赖锁定于 package、builder 配置和 lockfile，桌面与 HTML 使用同一份工作台成品。
