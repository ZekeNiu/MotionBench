# MotionBench 2.7.2 · 等长力量短标签与表格对齐

2026-10-07。**置信度：高**，依据为当前成品的模型检查、浏览器测量、同数据比较及实际 PDF 导出和逐页检查。

## 调整结果

- 等长力量的“评价”和“关节平衡”状态统一使用绿色“达标”、黄色“关注”、红色“严重”。完整评价原因保留在悬停说明和读屏名称中；疼痛仍在实测值旁明确标注。
- 关节平衡未启用标准或未设等级区间时，灰色标签保留比值及左右侧，不再显示长状态文字。已设区间但结果无法分级时，显示灰色“未评”。配对名称和已配置的标准信息继续保留。
- 取消等长表格独有的加宽比例及 720px 最小宽度，与 CMJ、IMTP 使用相同图表分栏。常规数据在已检查的桌面宽度下，两侧边线一致，无需横向滚动。网页仍为 13px，PDF 仍为 12px；均值与 SD 可在完整数值之间换行，数字不拆位。
- 手机保留逐方向记录形式。异常长名称、超大数值等压力数据必要时仍可在表格内部滚动，整页不溢出。
- PDF 同步短标签和常规左右比例，仍按完整内容高度选择左右或上下结构；A4、白底数据行、长表续页及重复表头保持。
