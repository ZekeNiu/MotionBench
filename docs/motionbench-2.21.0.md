# MotionBench 2.21.0 使用说明

本版加入可按需添加的常用测试项目和大学生体测单项等级方案，并支持为通用项目选择报告图表。原有录入、报告和管理页面的布局继续保留。

## 添加常用项目

进入“项目与指标库”，点击“添加常用项目”，勾选本次需要加入目录的项目。常用项目初始全部勾选，可取消不需要的条目；评价方案另外选择。查看“添加内容”中的项目、指标和方案数量后保存。已经添加的条目继续使用当前设置，重复添加不会覆盖后来编辑的名称、协议或标准。

共提供以下 **12个项目、14个测量指标**：

| 项目 | 指标 | 单位 | 最佳模式选值 |
| --- | --- | --- | --- |
| 10米冲刺 | 完成时间 | 秒 | 最短有效时间 |
| 20米冲刺 | 完成时间 | 秒 | 最短有效时间 |
| 50米跑 · 学生体测 | 完成时间 | 秒 | 最短有效时间 |
| 立定跳远 | 跳跃距离 | 厘米 | 最远有效距离 |
| 传统505变向 · 左右 | 左脚、右脚转向时间 | 秒 | 两侧分别取最快有效试次 |
| T形变向 · 码制 | 完成时间 | 秒 | 最短有效时间 |
| 握力 · 左右 | 左手、右手握力 | kgf | 两侧分别取最大有效值 |
| 杠铃背蹲 · 实测1RM | 实测最大成功外负荷 | kg | 最大有效负荷 |
| 卧推 · 实测1RM | 实测最大成功外负荷 | kg | 最大有效负荷 |
| 传统硬拉 · 实测1RM | 实测最大成功外负荷 | kg | 最大有效负荷 |
| 800米跑 · 学生体测 | 全程完成时间 | 秒 | 最短有效时间 |
| 1000米跑 · 学生体测 | 全程完成时间 | 秒 | 最短有效时间 |

添加后，新建测试时选择这些项目即可直接录入，也可通过本次测试的Excel模板录入。800米、1000米按总秒数填写，例如4分30秒填 **270**。实测1RM每行记录一次完整1RM测试的最大成功负荷，包含杠铃杆；热身组和失败试举不作为完整测次。

新预设的时间、距离、负荷和握力使用正数；未测留空。项目协议、完整指标清单和资料来源见[常用测试与评价标准](preset-tests-and-standards.md)。

## 选择大学生单项等级方案

“评价方案”中的“添加参考方案”可单独添加以下 **4套方案**。选中方案时，缺少的50米、立定跳远和对应耐力跑项目会一并加入目录；已有测试记录的评价方案仍按原选择使用。

| 方案分组 | 适用单项 |
| --- | --- |
| 男生 · 大一/大二（2014） | 50米、立定跳远、1000米 |
| 男生 · 大三/大四（2014） | 50米、立定跳远、1000米 |
| 女生 · 大一/大二（2014） | 50米、立定跳远、800米 |
| 女生 · 大三/大四（2014） | 50米、立定跳远、800米 |

这些方案按教育部《国家学生体质健康标准（2014年修订）》的大学单项评分表判断“优秀、良好、及格、不及格”，使用与体测协议一致的正式登记成绩。选择实际性别、学年对应的方案，并使用“最佳”模式；性别未注明、不匹配或使用均值模式时，这套单项等级不适用。学年由实际情况选用，年龄不代替学年。[教育部原文件](https://www.moe.gov.cn/jyb_xxgk/xxgk/neirong/fenlei/sxml_twyjy/twyjy_tyws/tyws_xgzc/201407/t20140708_171692.html)、[高校公布的评分表](https://jwc.hnust.edu.cn/docs/2024-06/3ad7c9c4e8324cf2ac818e98d081dd0c.pdf)。

报告显示上述单项的等级；完整学生体测总分、加分和毕业成绩不由这三个项目推算。方案也没有预先为这些单项配置能力图分数。全部36个等级边界及原表页码见[标准对照表](preset-tests-and-standards.md#大学生单项等级的36个边界)。

## 设置通用项目的报告图表

在“项目与指标库”打开一个通用项目的项目编辑页面，在“报告图表”中勾选“在报告中显示图表”，选择图表样式和展示指标，再保存。

| 图表样式 | 适合查看什么 | 显示内容 |
| --- | --- | --- |
| 成绩条形图 | 左右侧结果或同单位的多个指标 | 本次计算后的实际成绩；不同单位分别绘图 |
| 重复试次点图 | 各次冲刺、跳远或完整1RM测次 | 实际有效试次及代表试次；只有一次也显示一个点，缺测保留试次位置 |
| 实测与目标 | 当前成绩与训练参考目标的差距 | 本次成绩和当前适用的参考目标，使用原单位比较 |

目标图需要该测试所用评价方案已经启用有效参考目标，且测量条件适用、单位一致。没有适用目标时，报告说明原因。缺测或无效值不绘制为零，图表也不从已有成绩推算其他试次。

常用项目中，握力和505默认使用成绩条形图，其余默认使用重复试次点图。结果表始终保留，关闭图表后仍可查看成绩与原始试次。原生专用项目继续使用自身的图表。

项目目录中的图表设置用于后续新建测试；已有记录保留创建时的图表设置。更改图形样式不改变测量值、等级或能力图给分结果。

## 理解选值和版本

“采用同一次代表试次”按项目的主指标选出一整次试次，其他逐试次指标采用该次对应值。均值模式先采用主指标有效的试次，再分别计算各指标的有效值平均。

“各指标独立选取”让每个指标在自己的有效试次中选值。握力左右侧、505左右转向可来自不同试次；均值模式也按各侧各自的有效值计算。有三次及以上有效值时，结果表显示均值和标准差；可计算且已启用CV的指标同时显示CV。

实际改变主指标、选值方式或有效选值方向时，软件会自动更新相应测量方法版本，并在保存预览中说明对后续标准匹配的影响。无需再为同一次变化手工加一次版本。修改名称或图表展示不改变测量方法版本；已有记录仍保留原测量方法。

## 阅读报告

测量成绩保留秒、厘米、kg、kgf等实际单位；参考目标用于同单位比较；大学生方案输出适用单项的等级。能力图采用所选评价方案配置的0–100分给分方法。查看成绩和图表时，应同时查看相应测试协议和评价方案。

添加项目或方案后，仍可通过“备份与恢复”导出完整JSONL。该备份包含新增目录和方案，以及原有记录、测量数据和人工正文；单条测试的JSON、HTML和PDF用于报告分享。
