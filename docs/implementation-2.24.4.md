# MotionBench 2.24.4 纵向比较显示设置

本次完善同一运动员多期报告的展示与保存，计算入口继续使用原测量、协议、单位和评价标准。

评价表将状态颜色集中在原短标签内；当双侧说明与标签表达相同内容时，仅保留一处。FMS标题、雷达、图例和结果表使用比较页专用布局，避免继承个人报告的横向容器规则。

`RingsideLongitudinalViews`为每个比较文档的`views.charts[chartId]`保存图中日期、图层选项与展示指标。图中日期始终是首页所选记录的非空子集，结果表和计算模型继续使用完整选择。FVP、弹性、IMTP和LVP的比较控件通过独立事件入口更新显示状态；HTML、JSON和完整备份保留这些设置。恢复旧文档时使用原默认展示。

保存图表显示设置时，控制器对普通视图自动保存建立等待屏障。图表写入成功或回退后，普通保存才读取当前快照，避免失败设置被随后发生的展开状态保存重新写回。实测IndexedDB写入失败、界面回退与原操作重试均由浏览器检查覆盖。

逐期FVP和弹性分析在宽窗口中采用两列，窄窗口单列。打印保留完整方法、解释与原始表格；长日期速度图按相同日期段交错排列不同指标，保持同排日期对应及公共坐标范围。

两个日期使用单一“变化”列；三个及以上日期使用固定首末、近期端点。百分数差值保留百分点计算，紧凑显示百分号，标题与辅助阅读提供准确含义；相对变化另行标明“相对”。

恢复交接时，实际资料库的物理文件已与10月17日备份不同，因此另建10月19日完整备份与独立基线。原基线、捕获器和失败记录均保留。新基线捕获器继续逐字段保护原记录、时间、正文与完整模型；资料副本验收窗口在工作台准备完成后隐藏，并关闭后台帧节流，避免桌面交互干扰且保留正常渲染。正式安装仍通过真实Explorer环境完成原目录升级，并逐文件核对当前备份。

最终核验与安装状态见[验收记录](acceptance-2.24.4.md)，操作说明见[使用说明](motionbench-2.24.4.md)。
