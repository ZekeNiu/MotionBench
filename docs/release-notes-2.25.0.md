# MotionBench 2.25.0

新增横向比较报告，可从一名运动员出发比较，也可让多人平等并列；沿用纵向报告的章节、图上表下布局和导出方式。

- 每人选择一条实际记录，并添加全库、指定专项或指定队伍参照；可结合性别、专项细分、测试年龄和日期窗口。
- 分开设置单次测试的最佳试次／试次均值与人群的最近测试／阶段纪录。每人等权，逐指标保留人数、来源和并列最佳，不补零、不拼接不同测试的伴随指标。
- 在资料管理中维护专项、主要细分和年龄区间，在指标库统一维护数值含义及表现方向。
- 横向报告独立保存正文和统计快照。重新打开保持原结果，更新参照时保留正文；HTML／JSON 可离线重开，PDF 默认包含所有参照组，并按人数分块。
- 支持横向报告的 AI 草稿、预览和应用流程，完整备份同时保存分类、报告和快照。
- 修复 PDF 中文文档属性在部分阅读器中出现错字的问题，保持页面内容和版式不变。

升级前请保留完整资料备份。回退 2.24.13 时应同时恢复旧程序和升级前资料；旧版本不能读取新建的横向报告。
