## 参考目标与置信度

软件修复、运算和上述工作流检查的置信度为高。文献人群、单位、性别／年龄／侧别及最佳／均值匹配已检查；来源及采用范围见 [本版说明](motionbench-2.16.0.md)。

文献均值与用户固定测力装置的可比性未知，未进行同设备研究验证。肩 ER:IR 人群均值仅供比较，髋 ER:IR 未新增虚构分界。Bohannon 男性腕伸首行的 20–29 岁匹配属于依据样本量及邻接年龄行的推断，原数值保持不变。

原生 Excel 检查采用应用自动化写入，不等同于逐键输入；自动扩展观察和操作方法在原生证据中单列。未运行实体手机、实体打印、新一轮在线模型内容质量或全新 Windows 机器安装检查。
