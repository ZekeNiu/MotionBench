# MotionBench 2.24.5：纵向报告评价与变化显示

表格中的结果未设置或未启用评价时，保留实测值与试次统计，不再显示灰色评价占位标签。快速摘要的“改善”数量使用绿色，“下降”使用红色；可判定方向的首末及近期变化使用同一颜色。

FMS 的变化列使用固定0–3分刻度的微型连线图，分别表示对应比较的起点与终点；0分的疼痛含义、双侧项目取较低分及原始记录保持原有规则。手机端比较表可横向滚动，变化列不再受到个人报告五列宽度规则的挤压。

等长力量继续显示“关节平衡”。完整配对使用已有个人报告比值；未形成完整配对时，报告显示所选日期及未选入的对应测量方向。需要同一关节完整且协议一致的配对方向才能计算比值。
