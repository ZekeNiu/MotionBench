## 判断依据与限制

软件修复、运算及上述成品工作流的置信度为高。用户已确认本次 DSI 缺失由忘记勾选可比性确认造成；本版增加提示，没有改变力的计算公式或放松测量条件。

已启用的区间决定评价颜色，参考目标决定目标达成度；两种配置可以产生“83.3% 且达标”等结果。没有区间时保留原有目标达成阈值。关闭指标评价会保留数值、目标和区间，但不参与评级或能力达成计算。相关旧 AI 解读会标记待复核，手写正文保持。

肩 ER:IR 人群均值及 SD 不提供个人合格区间，只有均值参考时保持灰色。髋 ER:IR 无新增虚构分界。已确认文献的性别、年龄、侧别及身体资料换算保留；固定测力装置与文献测量条件的可比性仍未知。来源与采用方式见 [本版说明](motionbench-2.16.1.md)。

没有访问用户真实浏览器资料库、用户问题工作簿或实际设备。没有新增实体手机、实体打印、在线 AI 内容质量或全新 Windows 机器安装检查。现有 Windows 启动器保留 Python 运行环境要求。
