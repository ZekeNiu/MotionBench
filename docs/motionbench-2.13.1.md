# MotionBench 2.13.1

2026-10-09。本版统一单人和多人录入，分开 Excel 模板下载与文件导入。

## 使用流程

1. 在“选择运动员”勾选一名或多名已建档人员，可按队伍和姓名、专项、编号筛选；筛选不会清除已选名单。
2. 在“设置本次测试”选择日期、测试方案、项目和等长力量方向；多人测试的身体资料按各自记录带入，不使用共同体重。
3. 进入“按项目录入”，可切换本次运动员手动录入，也可分别使用“下载 Excel 模板”和“导入 Excel 文件”。下载直接生成文件；导入打开上传、核对和保存窗口。

空项目默认预留三次测量；已有测量保留实际试次数。模板目标编号在本次录入期间保持稳定，重复下载或刷新不会另建目标。同一模板重复导入仍定位原记录。新增测试请返回报告后重新开始录入。

只进入录入或下载模板不会创建空测试记录。真实手动测量自动保存；导入先核对再保存。多人各自保存并独立切换，当前输入错误或保存失败时保留当前运动员以便修正。换传损坏或错误的 Excel 文件会使上一份预览失效。

在同一个页面刷新可恢复本次名单、选中的运动员和临时录入。已保存记录以资料库为准；保存中或保存失败的修改保留临时副本，外部改动发生冲突时载入资料库最新内容并提示核对。返回报告后，已保存测量保留，未测空草稿不入库。新建档案在首次保存测量时一并保存；Excel 使用已建档人员。
