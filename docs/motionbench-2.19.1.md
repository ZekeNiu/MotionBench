# MotionBench 2.19.1

本版同时提供 Windows 桌面版 `2.19.1-desktop.1` 和离线 HTML `2.19.1`，两版使用同一套计算、判定和报告界面。

## Windows 安装与更新

安装包增加安装向导，可以选择程序目录。运行桌面程序后，在侧栏底部打开“应用设置”，查看“更新与版本”、检查和下载新版本。“启动时检查更新”可以随时开启或关闭；下载完成后点击“重启并更新”。

从 `2.19.0-desktop.1` 升级时，先手动运行本版 Setup。后续版本可使用应用内更新。便携版在发现新版本后提供“下载便携版”，退出程序后替换便携程序。

安装目录与本机资料目录分开，升级、重装及卸载保留运动员资料和 AI 连接。更新前可在“备份与恢复”导出完整资料库。

## 判定与报告

- EUR 使用原始比值判断：大于 1.1 为“需要强调向心能力”，小于或等于 1.1 为“需要强调利用 SSC 的能力”。CMJ–SJ 增益采用同一方向；概览、能力分析、AI 输入与 PDF 一致。
- iDSI 直接展示 CMJ 与 IMTP 的冲量组成；本地建议直接说明相关动作、需要加强的方向及进阶条件。
- 能力分区使用浅底色三级标题带，动作使用白色卡片和柔和阴影。原始试次仍在对应动作下展开。
- 能力结构摘要更紧凑，整组没有有效数据的卡片隐藏。一张横向铺满；两张两列；三张宽屏三列；四张两列两行。窄窗口自动调整。
- 跳跃比较图统一使用 CMJ、SJ、DJ、Hop、CMRJ 短标签，表格保留完整名称。
- 摘要、人体图、概览和图例使用与结果表“评价”一致的状态色。

已有测量、试次、评价方案和人工解读继续保留。此前采用旧 EUR 方向的 AI 稿保留原文，可在解读编辑界面重新生成或复核。
