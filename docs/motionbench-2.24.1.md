# MotionBench 2.24.1：摘要与雷达图调整

报告首页的纵向比较“快速摘要”展示运动员基本信息、首末下降指标、首末改善指标及全部比较日期。两张变化卡沿用单次报告的样式，大字显示“X项”，下方小字列出具体指标，变化幅度见结果表。首末指所选记录中最早和最近的测试；是否改善按该指标适用且一致的评价方向判断，FMS明确标为动作评分变化。

损伤风险卡使用柔和的红、黄、绿背景，颜色交界有窄幅渐变，等级以“预警、关注、达标”呈现。各期数据仍保留左右侧和缺测位置。

雷达图的数据轮廓增加半透明填充。多期叠加时适当降低透明度，结合日期颜色、线型和实测点读取；力量百分比网格按数据范围使用整齐间隔，并保留100%参考。能力分、FMS和筛查继续使用各自的固定量表。

运动表现概览按实际已测能力维度展示：少于3个用表格，3个及以上用雷达图，不设原来的8个维度上限。

DJ“新增试次”修复了添加后定位输入框时的异常，连续新增、录入和保存使用原有流程。

## 查看示例

在首页运动员选择框搜索“示例运动员｜纵向比较（合成）”。示例包含2026-09-01、09-15、09-29、10-13四期测试，通过正常新建和录入流程保存。

选择全部四期可查看首末改善、下降、部分缺测及风险等级变化；选择任意一期可查看单次报告。示例中的人员和测量均为合成资料。
