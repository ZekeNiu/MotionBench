# MotionBench 2.25.0 使用说明

横向比较报告用于对照不同运动员的实际成绩，也可将个人成绩与资料库中的同类人员比较。它沿用“概览—具体数据—解读与建议”的章节，图表位于数据表上方。

## 创建报告

1. 打开“横向比较”，选择个人主角或多人并列视角。每名运动员选择一条实际测试记录。
2. 按需添加参照组：当前资料库、指定专项或指定队伍，再设置性别、专项细分和年龄范围。个人视角可匹配主角；多人视角使用界面列出的共同条件。
3. 明确选择全部历史、近 12 个月或自定义日期，并选择群体取样方式。仅比较多名运动员时可以不添加参照组。
4. 核对评价方案后生成。个人视角默认引用主角记录的方案，多人视角默认引用资料库默认方案。

“最佳试次／试次均值”决定每次测试如何形成代表成绩；“最近可比测试／阶段个人纪录”决定每个人在群体参照中贡献哪次成绩。这两个选择互相独立。

## 理解群体参照

| 取样方式 | 每个人的贡献 |
| --- | --- |
| 最近可比测试 | 每个项目及可比条件下，最近一次实际开展该项目的测试结果 |
| 阶段个人纪录 | 日期窗口内，每个指标按已确认方向选出的最佳单次代表结果 |

人员先按当前档案归组，再筛日期、测试年龄及测量条件，最后取样。符合条件的本人及归档人员参与统计；回收站和标记为示例的数据不参与。

每人每个兼容指标只贡献一个结果，测试次数多的人不会获得更高权重。均值是这些个人代表值的等权均值，人数按指标分别统计。最新测试缺失的伴随指标保持缺失，不从旧日期补入。比值等派生结果先在每个人的记录内计算，再跨人汇总。

阶段纪录需要明确“较大值更好”或“较小值更好”。无固定方向的普通数值采用最近可比结果，并标明实际口径；方向尚未确认时不推断最佳。等级、类别编码显示人数分布，不能作为连续数值平均。群体最佳保留来源与并列信息。

不同协议、单位、侧别或计算方法的结果分别呈现。体重、推进距离等合法个体输入保留各自取值。FVP 保留每人的完整分析曲线，群体参照使用参数统计。

## 专项、细分与年龄段

在侧栏“专项与年龄段”管理专项名称、细分称谓、细分选项和可复用年龄区间。每人选择一个主要细分；细分属于一个专项。更换专项后需重新选择细分。

分类重命名保留原有归属。旧专项按当前档案中完全相同的非空文本建立关系，不推测别名；旧细分为空。历史测试原文保留，新记录采用当前档案。未填写细分的人员仍可参加其他条件下的比较。

指标库统一维护结果含义和表现方向。“指标方向核对”集中列出未确认指标及与旧评价规则的冲突。切换评价方案会重新评分，不会改变阶段纪录的原始来源；旧评价规则保留原有计算。

## 阅读、保存与分享

屏幕一次展开一个参照组，图中运动员可单独选择；表格继续保留完整比较结果。每行可查看实际人数、采样日期与来源。差值表示高于或低于参照，不能解释为个人随时间的进步或退步。

报告保存独立正文、配置和统计快照。重新打开继续显示保存时的结果；点击“更新参照数据”或修改取样条件后重新计算，原正文保留，并提示其依据是否变化。

HTML 和 JSON 包含直接比较记录及群体贡献快照。离线重开保留统计结果；参照人员的快照不会自动建立一批在用运动员。PDF 默认导出全部参照组，也可选择当前组；人数较多时分块并重复必要的对象与表头。

完整资料库备份包括分类、横向文档与快照。AI 使用同一份统计事实生成独立草稿，仍需通过现有预览、应用流程进入正文。

## 升级与回退

升级前保留完整资料备份和 2.24.13 程序。本版增加独立报告存储；回退旧程序时同时恢复升级前的资料副本。新版本创建的横向报告不能由旧版本读取。

实际验收范围、文件校验和本机升级状态见 [2.25.0 验收记录](acceptance-2.25.0.md)。
