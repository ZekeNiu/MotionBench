# MotionBench 2.18.0-local 修改说明

四张方向卡片现置于“能力结构分析”顶部。力量、反应力量、速度、耐力的全部有效参数分别放入卡内，默认折叠，可独立展开；桌面两列、手机单列。切换判断依据只改变摘要，参数仍完整保留。

下方依次为跳跃FVP、跳跃FVP弹性框架、冲刺FVP、冲刺FVP弹性框架。力量卡可采用当前 SJ/CMJ 的跳跃弹性，速度卡可采用当前目标距离的冲刺弹性。ER 比较两端等比例变化的模型响应。

跳跃弹性图可切换“参数响应”与“固定当前预测跳高的 ER–EN 关系”；冲刺弹性图可切换“参数响应”与“弹性随距离变化”。右侧继续对照当前与情景结果，单端及联合曲线可独立开关。

目标距离和两套情景在失焦、编辑完成或 Enter 时自动校验保存。0% 为无变化；空目标跟随所采用完整试次末段；空情景及非法值显示字段错误并保留上次有效设置。草稿按记录和 SJ/CMJ 协议隔离，刷新与切换后可恢复。合法编辑局部更新，保留控件，并在一次鼠标点击结束后刷新布局。

导出前提交有效编辑，非法草稿会阻止导出并定位字段。HTML、JSON 和 PDF 固定导出开始时的数据快照，等待对应保存成功，避免等待期间的新编辑进入未保存的导出。JSON/JSONL、独立 HTML、Excel 支持新增设置往返；旧记录与旧模板兼容，保留项目 ID 与自定义名称。

PDF 跟随网页四卡参数的展开状态：摘要始终保留，关闭的参数不打印，展开表格可续页并重复表头。保留所选择的弹性图位与既有其他内容的打印策略。

冲刺弹性采用新论文的静止起跑、静风力速运动方程，沿用已有 F₀、V₀、身体资料及空气条件，独立于原冲刺最优模型。有阻力采用单端正向 1% 扰动，无阻力采用解析弹性；有限情景完整重算。非零风仍保留原冲刺 FVP，弹性面板说明不可用原因。

原有跳跃 FVP、90°/30° 最优剖面、经典与距离平均参数换算，以及冲刺 FVP、Samozino 2022 最优剖面算法保留。SJ/CMJ 回退规则已统一；显式无效蹬伸距离在原始表中如实显示。

AI 资料使用同一组弹性、情景与有效性结果，并绑定跳跃协议。折叠、视图和曲线显示变化不会使解读过期。

计算审查、来源及解释边界见 [冲刺弹性方法](sprint-elasticity-method.md) 与 [数据契约](dual-elasticity-data-2.18.0.md)。最终检查绑定于 [验收记录](acceptance-2.18.0-local.json)。本次不把原生 Excel 重算、真实设备测量或垂直预印本全部实验条件视为已验证。
