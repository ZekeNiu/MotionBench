- 通用项目在“项目与指标库 → 编辑项目设置 → 报告图表”配置六种图型，支持指标选择、顺序、预览和显式关闭。默认使用表格。
- 报告保留左图右表、完整测量与评价、原始试次、适用的重复统计和备注。原值按单位分图；散点只取同次配对；雷达要求 3–8 项均有有效结果和适用的明确给分规则，缺项时保留表格并说明原因。
