# MotionBench 2.24.8

纵向比较中，除“双侧差异”外，评价标签统一放在数值后方：红色“预警”、黄色“关注”、绿色“优秀”。双侧差异保留侧别描述，有效的自定义灰色等级保留原名称。原有等级名称和判定来源可在提示中查看；本轮不调整评价阈值。

力量结果有疼痛记录时，优先显示红色“预警”，提示说明“疼痛记录”；原数值、力量目标、双侧差异计算和风险筛查保持。疼痛是已有录入信息，不是根据力量差异推断的结论；没有测量值时继续显示“—”。

mini趋势图根据实际适用标准显示浅色底色。配置区间保留原边界和缺口，目标型评价使用该项目真正生效的阈值及方向，FMS等离散评分使用等级色带。只有参考均值的资料不额外生成优劣分区。疼痛预警不会改变力量标准的底色。

本轮采用按变更风险验收：重新检查受影响的评价投影、纵向报告、交互、精简实际PDF和打包程序；未改动的计算、存储及单期报告依赖经过逐文件核验的完整基线。真实资料备份、安装重开、快捷方式和GitHub附件校验继续保留。详情见[验收策略](verification-strategy.md)及[本轮验收记录](acceptance-2.24.8.md)。
