# MotionBench 2.11.0

2026-10-07。本版基于 2.10.0，优化悬浮提示与下拉选择，补全反应跳测试，并加入“训练方向分析”。

## 使用变化

- 悬浮提示统一为应用内提示；选择器保留稳定的页面节点。侧栏队伍管理置于运动员管理上方，分组标题左对齐。报告标题改为“运动表现与损伤风险筛查报告”。
- “AI 服务”与“参考资料与方法”分别进入。参考资料列出文献、采用的数据与方法；现行原始评价区间保持不变。
- 通过本机启动器运行时，可将 AI 服务配置保存在当前 Windows 用户的本机加密存储中，后续启动使用已保存配置。配置位于项目目录外；JSON、HTML 和备份不包含 API Key。直接打开离线 HTML 时仍使用临时 Key。
- 指标库新增 DJ、Hop Test、CMRJ。跳跃组合图使用跳高柱（左轴，cm）和 RSI 点（右轴，m/s）；有记录的项目同时进入结果表。
- Hop 可直接录入设备汇总，也可录入数量不限的逐跳数据。有效跳不超过 5 个时全部采用，超过 5 个时按单跳 RSI 取前 5 个，同值保留先后顺序。所有输入、未采用跳及实际数量保留。多组完整 Hop 测试可作为独立重复测试；一组内的多跳不充当独立重复样本。
- CMRJ 分开记录首跳和反弹跳，组合图采用反弹跳结果。首跳 RSI-modified 使用起跳用时，反弹 RSI 使用触地时间。

## 训练方向分析

该分类包含跨测试计算结果，不生成新的动作测试项目，不加入能力评分或雷达总分。目录开关用于新测试的默认配置；当前记录可单独选择展示指标。

| 指标 | 计算与条件 |
| --- | --- |
| EUR、CMJ–SJ 增益 | CMJ 跳高 / SJ 跳高；增益为 `(EUR−1)×100%`。结合两项绝对成绩解释，无通用优劣分界。 |
| DSI / fDSI | CMJ 推进期峰值力 / 等长峰值力；需确认相同单位、净／总力口径与可比协议。`<0.60`、`0.60–0.80`、`>0.80` 分别提供动态力量表达、并行发展、最大力量储备的文献启发，不作为能力等级。 |
| iDSI · 匹配时窗 | CMJ 完整推进期冲量 / IMTP 同等时窗冲量。每个参与汇总的 IMTP 积分时窗必须与 CMJ 代表推进期时长一致。 |
| iDSI · 固定 250 ms | CMJ 完整推进期冲量 / IMTP 起点后 0–250 ms 冲量；只有分母固定为 250 ms。 |
| RQR / FT/CT 反应比 | DJ 的 FT/CT 代表值 / Hop 的 FT/CT 代表值。逐跳 Hop 为此单独按 FT/CT 取前 5 个，不复用图表的跳高／触地时间排序。只有 DJ 45 cm 三次均值、Hop 完整十跳的时间比前五等主要取值条件符合时标为原协议 RQR；其他条件注明当前协议。 |
| ASR、SRR | MSS−MAS、MSS/MAS。使用相同速度单位，不以 VIFT 替代 MAS；现有速度章节的参考分型保持原有边界。 |

冲量以 N·s、时窗以 ms 录入，必须来自设备或原始力时数据积分，并确认双方力的口径。缺测或时窗不符时显示原因，不由稀疏时间点或“峰值力×时长”估算。最佳模式保留同一尝试的关联测量；均值模式使用各测试代表值，跨动作比值不生成虚构的配对 SD 或 CV。

## 数据兼容与回退

保留记录、运动员、项目和指标的既有编号、原始数据、评价标准及手动分析。历史记录默认不启用新增三个跳跃项目；新增空白默认值不使旧分析无故过期。实际新测量、标准或分析开关变化仍会触发更新提示。

历史自定义项目若已使用 `dj`、`hop` 或 `cmrj` 编号，继续按原自定义结构处理，不覆盖为新增动作；同编号自定义指标同样保留。2.10.0 已作为 Git 标签保存，完整运动员资料仍应使用应用的“备份与恢复”导出。
