# MotionBench 2.25.2

- 纵向与横向比较报告的损伤风险、运动表现雷达图使用相同画布高度，改善两张卡片的大小协调。
- 多维风险图与等长力量图收紧半径，保留全部维度和标签。等长力量达到 10 个部位时继续使用雷达图。
- 没有能力结构小卡片时，移除其空白占位；有小卡片时继续显示。

本次变更限报告显示，不改变测量、评价标准、统计结果或报告正文。2.25.1 是本机修正版本，本次一并公开发布。

Windows 版本为 `2.25.2-desktop.1`，离线 HTML 为 `2.25.2`。本轮只执行与图表调整相关的最小必要验收，详见 [验收记录](acceptance-2.25.2.md)。
