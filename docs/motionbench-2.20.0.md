# MotionBench 2.20.0

Windows 正式版为 **2.20.0-desktop.1**，离线 HTML 为 **2.20.0**。桌面、浏览器和模拟演示共用同一套评价与报告。

## 评价方案

编辑页面分为“项目标准”“能力图设置”“记录预览”，顶部保留方案名称、发布版本、未保存状态和关联记录数。切换页面保留草稿。

项目标准按项目和指标定位，分别设置目标、等级和适用条件。能力图按能力逐项配置，可选一个指标、固定多个指标等权平均，或不显示此能力；给分支持按目标换算、按区间给分及按数值对应换算。对应点之间采用直线换算，结果限制在 0–100 分。平均先分别给分，再取平均；缺少任一有效成员时列出具体缺项。代表指标缺测时保留缺测状态。

记录预览直接比较已发布版和草稿对已有成绩、单项评价和能力分数的影响，不改变记录。发布前查看配置差异和所选记录的结果变化。

## 项目与指标库

侧栏入口改为“项目与指标库”，项目按主能力组织。桌面使用列表和详情双栏；窄窗口从列表进入详情，搜索和筛选可返回结果。

搜索具体指标时显示所属项目、指标名称和单位，并定位到对应指标。详情说明测量方法、录入内容、结果来源及代表试次选取。项目和指标分别编辑；保存前列出修改内容和测量协议影响。配置评价标准时先选择方案，返回后保留原搜索、筛选和定位。

## 计算、保存与报告

- 代表指标和平均成员使用同一个计分入口；旧方案保留既有比例规则。未配置或关闭的能力不生成能力轴。
- 删除最后一个适用条件组后恢复通用标准；真实条件不匹配时显示原因。实际分析依据变化时保留人工正文并标记复核。
- 分数与等级分别计算，代表能力沿用选定指标的既有评价，平均能力使用已设置的平均分区间。能力图、明细、AI 输入及导出统一使用“分、满分 100”。
- 普通成绩保存只提交当前记录及必要摘要，共享配置独立更新。恢复、历史资料清理和完整备份核验资料版本，避免交错操作导致资料混合。
- 保存中的取消、关闭和导航统一受保护；迟到的异步结果只处理发起时的编辑会话。设置返回恢复原管理页面与草稿。
- “能力结构分析”和其他三级标题使用相同结构、宽度及 16px 字号，底纹为 `#f7f9fc`，文字为 `#45546a`。下属卡片和 PDF 同步统一。

原始测量、人工正文、参考均值及其比较行为、稳定编号继续保留。旧方案中的代表指标配置按原比例规则运行；编辑并发布新的给分方法后按新规则运行。

## 升级

从 **2.19.1-desktop.1** 可通过“应用设置 → 更新与版本”更新，或运行正式 Setup。安装版沿用原安装目录与当前 Windows 用户资料目录。便携版退出后替换程序文件。

下载及迁移说明见 [Windows 桌面版](windows-desktop.md)，各项核验和成品校验值见 [验收记录](acceptance-2.20.0.md)。
