# MotionBench 2.26.2：查看与比较报告

报告采用统一墨青风格。个人图中的相关测试使用协调颜色；纵向历史日期从青经蓝至靛变化，最近测试日用深墨青突出。同一天的多条记录共用日期颜色，可通过真实标题和短编号区分。日期颜色表示先后，不表示成绩好坏。

横向报告中，同一运动员在各图保持同色，群体参照使用中性色。“报告重点”和“比较基准”位于主标题上方；需要调整某张图中的运动员或日期时，使用该图的选择项。日期或人数较多时，可以缩小当前图的显示范围，原始记录继续保留。

评价、疼痛和风险标识沿用原有含义。已有报告重新打开后使用统一外观；正文和已有测试资料仍可继续使用。

首页按“选择运动员 → 测试记录 → 查看报告”操作。两个选择区可以展开、收起；收起后显示已选摘要。勾选期间继续显示原报告，点击“查看报告”后才应用。需要放弃这次选择时，点击“撤销选择”。

先选择运动员，再选择其已有测试记录。一人选择一条打开个人报告，一人选择多条打开纵向比较；多人比较时，每人选择一条记录。测试日期不会自动代选。同一天有多条记录时，可根据标题和编号区分。

“群体参照…”位于“选择运动员”展开区内。弹窗中设置成员条件、统计日期和每人取样方式，确认后再点击“查看报告”。取消弹窗会放弃该弹窗中的改动。已选群体可以从同一入口重新编辑或移除。

可以将群体与运动员一起比较，也可以只选择群体查看群体报告。纯群体报告使用群体设置中的统计日期，不需要个人测试记录。群体支持最近可比测试、期间最佳成绩和期间均值；期间均值先计算每个人的有效测试均值，再对人等权平均。各指标显示实际人数和来源。

群体指标适用多个评价标准时，需要在对应群体弹窗中明确选择统一标准，确认后再次查看报告。统计日期保存后固定，重新打开不会自动重新取样；“更新参照数据”才重新计算。

“报告设置”中可以调整比较报告的评价方案和名称。报告重点、比较基准、图表和人工正文仍在报告内维护。已保存横向与群体报告位于“测试记录 → 已保存报告”。
