# MotionBench 2.24.4：纵向比较显示设置

在首页选择同一运动员的多条记录后，进入纵向报告。每张图可独立勾选要显示的日期，至少保留一个日期；再次打开该比较时会恢复各图的选择。结果表、首末与近期变化、AI分析依据和完整记录导出始终使用首页选中的全部记录。

跳跃FVP和冲刺FVP可调整曲线图层、置信区间、显示范围及参数；弹性分析可切换已有视图和图层；IMTP可切换纵轴单位；负荷－速度图可选择动作与已有图层。设置与对应比较文档一同保存，也可通过独立HTML或JSON恢复。

FMS标题、图表和表格采用协调的紧凑布局。评价颜色集中在原有短标签上，重复的双侧说明合并显示。FVP与弹性的逐期分析在宽窗口中每行两期，窄窗口中每行一期；PDF保留完整分析、方法和原始数据。

比较两个日期时，结果表只显示一列“变化”；三个及以上日期分别显示固定的“首末变化”和“近期变化”。百分数指标的差值使用紧凑的百分号显示，悬停或辅助阅读可查看“百分点”的完整含义；相对变化明确标注“相对”。

安装包和便携版见[2.24.4版本页](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.24.4-desktop.1)。升级时沿用原安装目录。[2.24.3回退版本](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.24.3-desktop.1)继续保留。核验及安装结果见[验收记录](acceptance-2.24.4.md)。
