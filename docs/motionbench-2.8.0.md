# MotionBench 2.8.0 · 管理中心与报告工作台

2.8.0 将资料管理与报告选择分开。继续使用银灰界面、现有报告图表和离线单文件 HTML；原有测量公式保持不变。

## 使用流程

报告工作台中，先搜索运动员，再选择测试记录；可按队伍筛选，测试按日期排列。切换运动员会恢复上次查看的记录，否则打开最新记录。没有测试时显示空状态。

管理中心提供运动员、测试记录、测试项目库、指标库、评价方案、备份与恢复六个入口。支持先建档后测试、同名运动员、搜索筛选、分页、批量调整队伍或评价方案、归档和回收站。删除运动员连同其测试处理，恢复后保持归属；永久删除会单独显示影响数量并确认。

浏览管理列表保留当前报告。点击“查看报告”才进入相应报告；从管理列表进入录入后返回，会恢复列表条件、页码、滚动位置及此前报告。AI 服务与参考资料保留在应用设置，当前报告的 HTML、JSON、PDF 导出位于报告工作台。

## 共用评价方案

单次测试只选择方案与查看生效标准。特殊标准通过复制方案创建；方案可命名、编辑、设为默认、停用及查看关联记录。新测试优先沿用最近未删除记录的在用方案，否则采用默认方案。停用方案仍供既有记录使用。

方案包含指标目标、方向与等级、参考依据、能力汇总、不对称阈值、等长目标、关节平衡及 LVP MVT／素质区间。编辑先保留草稿，核对变更和影响条数后保存，并可恢复上一版。

保存后，关联的历史和归档记录采用最新标准。原始测量值、单位、协议、总力／净力及 MV／PV 口径保持原样；条件不匹配时保留实测结果，不套用该项标准。现有手写／AI 解读保留，生效评价依据变化后标记待复核，过期生成任务无法覆盖正文。

已导出的 PDF 与独立 HTML 保留导出时的内容。后续更新只影响本机资料库内仍关联该方案的记录。

## 迁移、备份与回退

在原路径、原浏览器打开新版，会将旧资料写入暂存 IndexedDB，核验成功后切换。按规范化评价配置及测量条件归并方案，默认使用关联记录最多的方案。旧浏览器存储继续保留，可在“备份与恢复”下载迁移前资料。不会为无测试档案自动生成记录。

完整备份为 `.motionbench.jsonl`，包含队伍、空档案、归档／回收站、项目库及方案。支持分批处理，不沿用旧 JSON 的 50 MB 总量限制。导入先完成结构、条数和关联校验；失败不替换原库。合并同编号不同内容的方案时创建新方案并重映射导入记录；本机现有方案和默认选择保持不变。

“恢复上次资料库”可撤回最近一次成功导入。回退应用到 [v2.7.2](https://github.com/ZekeNiu/MotionBench/tree/v2.7.2) 时，优先使用迁移前备份。旧版兼容 JSON 已通过 v2.7.2 模型校验，包含未删除的已测试记录与当前生效标准，不包含队伍、空档案和回收站信息。

## 本版验收

最终成品哈希、实测耗时和证据索引见 [2.8.0 验收摘要](acceptance-2.8.0.json)。

- 158 项模型检查；Chrome、Edge 管理流程及管理操作、失败恢复共 46 项浏览器检查。
- 300 名模拟运动员、3000 条完整记录；两个浏览器分别验证加载、筛选、编辑、独立进程重启、约 260 MB 完整备份往返。记录、档案、队伍、方案、目录及当前选择均逐项核对。
- 桌面、低矮窗口、手机尺寸；18 组方案编辑布局检查，另含列表、录入、生效标准视图。
- 实际点击 PDF 导出，覆盖 Chrome、Edge、手机、130 个自定义指标的长报告及失败后重试，共 61 页。检查完整行、数值、图表、A4 页面和渲染；31 个不同页面目视检查，其余 30 页与已检查页面逐像素一致。
- 独立 HTML 冻结标准并离线重开，旧 JSON 兼容，保存失败重试、快速连续修改、损坏导入不替换原库、方案冲突及旧阈值显式修复。


容量实测（300 人／3000 条模拟记录）：

| 浏览器 | 名单就绪，3 次 / ms | 最慢筛选 / ms | 打开记录 / ms | 保存 / ms | 备份 / 恢复 / s | 浏览器重启后页面就绪 / ms |
|---|---:|---:|---:|---:|---:|---:|
| Chrome | 225 / 168 / 171 | 132 | 36.4 | 3.9 | 2.76 / 3.18 | 358 |
| Edge | 228 / 181 / 174 | 137 | 37.2 | 12.0 | 2.84 / 3.10 | 326 |

这些容量结果来自本机 Windows 与隔离 Chrome／Edge 的模拟数据，不代表所有设备。AI 输入和过期任务保护使用模拟响应，本版未新增真实 AI 内容质量结论。手机使用浏览器尺寸模拟，未进行实体手机与实体打印验收。

源码、两个干净 HTML 和本版验收摘要进入 GitHub；个人运动员资料、本地备份、密钥与测试过程文件不提交。
