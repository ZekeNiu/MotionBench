# MotionBench 2.20.1 修订说明

本版为 Windows **2.20.1-desktop.1** 与离线 HTML **2.20.1**，修复能力雷达图和评分明细组合过高时无法生成 PDF 的问题。

2.20.0 的本机补验发现，包含能力图和三张评分明细表的卡片超过单页正文容量，触发超页保护而中止导出。该次没有生成 PDF，未发现资料改变。已公开的 2.20.0 程序和历史验收保持不变，详细记录见 [公开发布与补验](publication-2.20.0.md)。

2.20.1 让过高卡片按图表与表格内容分段输出，概览标题与首图保持相邻，较短卡片仍整块展示。能力评分、等级、参考均值、原始测量和人工正文的计算与内容保留。

新增专项使用 1、3、7 轴能力图及双成员平均评分的合成资料，核对雷达标签、各评分明细、人工正文和原始试次表的连续分页。专项 10 份 PDF 共 75 页：44 页直接目检，31 页与已目检页的渲染像素完全一致；另对最大混合 7 轴样例的 15 页进行了独立视觉复核。原有 4 份合成 PDF／26 页也按新成品验证。全部范围及实际安装、公开网址和本机验收状态见 [本版验收](acceptance-2.20.1.md) 与 [发布核验记录](publication-2.20.1.md)。

安装版可在“应用设置 → 更新与版本”更新，或运行新 Setup；便携版退出后替换程序文件。程序更新与资料恢复分开处理，重要测试批次仍应另存完整 JSONL 备份。
