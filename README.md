# MotionBench

跨项目的运动表现评估与训练建议工作台。当前版本 **2.7.1**。录入、计算、图表、备份与 PDF 导出均可离线使用。

![MotionBench](assets/motionbench-logo.svg)

### 打开与使用

- **离线评估**：双击 `MotionBench.html`，无需安装。直接打开 HTML 时，AI 服务需要允许浏览器跨域访问。
- **使用中转 AI 服务**：Windows 双击 `Start_MotionBench.cmd`，在自动打开的页面中使用；保持启动窗口开启。需要 Python 3.10 或更新版本。其他系统运行 `python3 scripts/serve.py`。
- **更新旧版**：`Ringside_Boxing_Assessment.html` 保留为内容相同的兼容入口。把新版放回原文件位置，用原浏览器打开，可继续访问该路径的记录。切换到新文件名、另一浏览器或本机启动入口前，请先在旧页面“保存与导入”中导出运动员库，再导入新入口；不同页面地址的浏览器数据不会自动合并。
- 下载后的两个 HTML 均可独立工作。无需使用 GitHub 网站上传测试数据。

### 两种建议有什么区别

| 入口 | 用途 | 使用方式 |
|---|---|---|
| 生成离线摘要 | 按规则整理测试发现和基础建议，作为手写解读的起点 | 无需联网或密钥 |
| 生成 AI 综合建议 | 综合指标关系、专项、训练背景和周安排，生成有剂量、取舍、进阶条件的教练建议 | 需要 AI 服务、文本模型和可用额度 |

AI 建议以最多两页 A4 为目标，生成后使用实际打印样式预检；超长时自动精简一次，保留动作剂量和关键调整条件。正文集中于本次训练需要，不加入泛泛免责声明。

点击“应用草稿”才更新正文，并保留上一版。AI 状态与已等待时间仅在解读编辑页和 AI 设置页显示，可取消等待或重试。生成期间可继续查看同一次测试，完成后返回解读页主动查看草稿；始终留在解读页且没有其他对话框时，会自动打开预览。切换运动员或测试记录会清除旧任务，未完成或过时的结果不会替换正文。

### AI 设置与密钥

在“应用设置”填写 HTTPS API 基础地址与密钥，点击“读取可用模型”，选择文本模型。不同服务的模型名称并不通用。读取模型成功后，实际生成仍可能受额度、模型权限或响应速度影响。

API Key 仅在当前页面和请求的内存中使用，不写入源码、浏览器存储、导出 HTML、运动员库备份或 PDF。刷新页面后需重新填写。浏览器输入不会修改磁盘上的 HTML，项目也没有自动 Git 提交、推送或测试数据上传功能。手动将密钥写入代码再提交则会泄漏，请勿这样保存密钥。

本机启动入口只监听 `127.0.0.1`，把当前请求转发给你配置的 HTTPS 服务；不保存密钥，不记录请求内容。AI 会收到当前测试与训练背景，不发送姓名字段或其他运动员记录；自由备注请自行去除身份信息。导出 HTML 会移除本机连接令牌，仍可独立打开。

如果模型列表可读、聊天接口可调用，但直接打开 HTML 仍报网络错误，服务可能拒绝浏览器预检。请使用本机启动入口；修改密钥或关闭浏览器安全保护不能修复服务端预检。

## 评估功能

- 运动员库、历次测试、测试项目库与自定义指标；专项和惯用手分别填写。
- FMS、等长力量、CMJ/SJ、IMTP、负荷-速度、MAS/MSS、30-15 IFT、乳酸等测试与报告。
- 同条件重复试次按最佳或均值汇总；至少 3 个有效值显示均值、样本 SD 与适用时的 CV。缺测不当成零。
- 等长力量保留五轴雷达；桌面左图右表，手机按方向展示。PDF 根据完整图表高度选择左右或上下排版，长表逐页续排。
- HTML/JSON 备份、可编辑报告与离线 A4 PDF。图表和计算不依赖联网。

更换专项时，请核对本次评价标准、协议和适用人群。部分内置测试与参考原用于拳击，品牌更名不会自动把这些标准变成跨项目通用常模。原始方向、单位、公式、历史记录和导入结构继续兼容。

页面与 PDF 采用统一的银灰样式，数据行白底。低矮窗口的侧栏可整体滚动，顶部关闭按钮保持可见；重新打开时会显示当前导航项。

方法说明：[速度参考](docs/speed-reference.md) · [软件结构](docs/architecture.md) · [本版验收](docs/motionbench-2.7.1.md)。

## 开发与验证

需要 Python 3.10+ 与 Node.js 18+。构建使用已固定并校验哈希的本地库，不下载 CDN 依赖。

```powershell
python scripts/build.py
npm ci
npm test
npm run test:ai-service
node tests/ai-scope-browser-tests.cjs
node tests/sidebar-browser-tests.cjs
python tests/local-server-tests.py
```

`src/` 是正式源码；修改后重新构建两个内容相同的 HTML。内部 `Ringside*` 模块名与旧文件名保留用于兼容，不代表仍以拳击作为产品定位。

可用 `node tests/live-motionbench-tests.cjs` 核对真实中转服务，密钥仅从进程环境 `RINGSIDE_AI_KEY` 读取；该测试使用独立浏览器和明确模拟的数据，会产生真实模型调用费用。默认服务为 `https://api.apikey.fan`，模型为 `gpt-6.1-sol`；先启动本机入口。它不会读取个人浏览器中的运动员记录。

`output/`、本机备份、密钥文件和验证过程文件不进入仓库。发布包仅包含干净应用、启动入口和使用说明。

## 第三方组件

离线 PDF 使用 html2canvas 与 jsPDF；来源、版本和许可证见 `vendor/versions.json` 及同目录许可证文件。
