# MotionBench 2.26.3

纵向报告的变化趋势图统一使用 160 × 72 像素画布。同一份报告按全部趋势图的纵轴刻度统一留白，使不同测试的实际绘图区对齐；各指标继续使用自己的单位、刻度范围和评价依据。

选择较多测试日期时，屏幕上的结果表在表格内部横向滚动。打印和 PDF 按日期分组展示结果，每个指标保留一张包含全部所选日期的趋势图。悬停、键盘或触屏仍可查看完整日期、读数和相邻变化。

本版同时包含雷达图和 mini 图底色恢复：雷达保留原半透明填充及缺测扇区，图内底板恢复原样，mini 图的评价区间底色保持原透明度。墨青主题、日期配色和运动员配色继续沿用 2.26.2。

首页选择、数据录入、群体参照及已保存报告的操作见 [2.26.2 使用说明](motionbench-2.26.2.md)。
