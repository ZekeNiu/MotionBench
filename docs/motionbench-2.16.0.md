# MotionBench 2.16.0

本版修复 Excel 续行身份误报和 FMS 单项评分误判，按训练方向重排概览，增加 F₀ 与 V₀ 同时变化的响应曲线，并统一等长力量方向、ER:IR 运算及共用参考目标。

## 录入与历史数据

可变测量页使用真正的 Excel Table，字段映射与身份清单独立存放。LVP 每人预留15行，FVP30行；已有数据之后仍追加这些空行。单人新增测量行缺身份时唯一绑定，多人从“运动员／测试”选择。旧模板仅补缺失编号，不覆盖已有冲突，也不按上一行猜测归属。普通试次编号可自动分配，重复编号拒绝；Hop、IMTP 的关联编号仍须明确填写。

FMS 按动作的单项／双侧属性读取评分。历史单项动作中的无关空侧别字段会清理，原评分、疼痛与备注保留。单边缺测不能算作完整双侧动作，疼痛计零并保持完成情况的独立含义。

## 报告与联合响应

概览先显示 SJ FVP、SJ 弹性、CMJ FVP、CMJ 弹性，再显示 EUR、DSI、SRR。有效结果独立呈现。EUR 按未舍入值与1.1比较：低于时发展 SSC，高于时发展纯向心，等于时并行。DSI 小于0.60发展弹道与快速力量，0.60至0.80并行发展最大力量与快速力量，大于0.80发展最大力量。iDSI 保留独立积分时窗，不套用 DSI 分界。

速度耐力卡先用已启用的 MSS、MAS 目标判断方向，无有效目标时显示 SRR 结构类型；缺测一端仍保留另一端的有效结果。心肺卡按可用的摄氧量和第二阈值目标给出方向。DJ、Hop、CMRJ 使用各自结果和标准。

弹性范数 EN = √(Fₑ²+vₑ²)，两端各提高1%的局部高度增益 = (Fₑ+vₑ)%。有限幅度收益用原模型重算。三条曲线可独立勾选；联合曲线横坐标 x% 表示 F₀、V₀ 各改变 x%，不相加单端收益。全部取消时提示选择。SJ、CMJ 分别保存；PDF 与独立 HTML 保留选择。

弹性来源：[Li et al. 2026, Beyond Imbalance: An Elasticity Framework for the Distance-averaged Force-Velocity Relationship in Vertical Jump](https://doi.org/10.64898/2026.09.01.748530)。模型响应是参数变化情景，实际训练适应仍需复测。

## 等长参考

肩与髋的旋转平衡实际按 ER/IR 计算。既有原厂配对和共用规则一次性迁移，区间倒数转换并交换端点和开闭边界；无法转换的规则保留原始副本、停用评价并提示核对。稳定编号与旧名称读取保持兼容。

全部非示例共用方案仅补空白目标一次。手填绝对目标优先；后续清空或编辑不会自动补回。参考配置可编辑固定 N、N/kg、性别、年龄、侧别及来源；必要身体资料不足或 Nm 无法换算时不生成目标。单一力量参考值低于时显示黄色“关注”，达到时显示绿色“达标”，不由文献均值设置红色“严重”分界。有分级区间的评价继续使用原规则，疼痛和双侧差异独立评价。

| 数据源 | 录入范围与采用方法 |
|---|---|
| [Catenaccio et al. 2017](https://einsteinmed.edu/uploadedFiles/labs/michael_lipton/Characterization%20of%20Neck%20Strength%20in%20Healthy%20Young%20Adults.pdf) | 18–35岁健康成人；颈屈、伸、侧屈；Table 2按性别和最佳／均值模式匹配均值，单位N。 |

| [Bohannon 1997](https://www.fisiotools.it/wp-content/uploads/2022/04/2016-09-12-Normvalues-Bohannon_1997.pdf) | 20–79岁成人；Tables 7–8肩伸、肘屈伸、腕伸、髋屈／外展、膝伸、踝背屈均值；体重百分比换算为力。膝伸部分观察受650N仪器上限影响。 |

肩、肘、腕按已有惯用手匹配文献优势／非优势侧；未知惯用手和未记录优势腿的下肢采用非优势侧共同参考起点。来源未覆盖的方向保持空白，髋 ER:IR 无新增虚构分界。文献测量方法与实际固定测力结果的可比性尚未通过同设备验证。

ER:IR 的文献人群均值保留为数值参考，不按比值高低自动划分关注／达标；已有启用评价区间才产生颜色判定。力量评价因本次规则发生变化时，对应旧 AI 解读会被标记为需要更新，原始测量和手写内容保留。

Bohannon Table 7 男性腕伸首行年龄印为20–39；该行样本量16对应Table 2的20–29组，且下一行单列30–39。本版按20–29组匹配，保留原数值。这是依据表内一致性的分组推断，原表存在排版疑点。

重复等长表保持整体宽度与桌面左图右表，七列宽度依次为14%、20%、23%、7%、12%、9%、15%。名称来自方向目录，实测、统计和目标统一L/R；差异统一左侧更弱／右侧更弱。

人体图只对本次有实际测试记录的部位显示圆圈，未测部位不显示占位圆圈。有效零值、疼痛记录和 FMS 单边已录入的部分结果保留；只有目标配置或备注不算已测。灰色圆圈表示已测但尚未评价，原始数据和评分规则保持原样。

## 使用与回退

双击 MotionBench.html 离线使用。兼容入口 Ringside_Boxing_Assessment.html 内容相同。Windows 启动包提供 Start_MotionBench.cmd，AI 中转需要 Python 3.10或更新版本。

升级前完整备份可用于恢复旧资料；远程回退标签 `rollback-v2.15.0-20261009` 指向已核验的2.15.0提交 `206bf47cc558e1ca4c9c7aa86c561c2e711ab41d`。仅替换HTML不会逆转已保存的ER:IR及共用方案迁移。
