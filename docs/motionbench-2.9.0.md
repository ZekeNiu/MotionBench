# MotionBench 2.9.0

本版重整数据录入、人员管理、指标标准与报告操作。继续以两个内容相同、可独立离线打开的 HTML 交付；旧文件路径及浏览器资料库保留。

## 使用流程

侧栏固定显示数据录入、测试记录、运动员管理、队伍管理、测试方案、测试项目库、指标库、评价方案。品牌区域返回报告首页；完整资料库备份与应用设置位于底部。

数据录入依次选择运动员、设置本次测试、逐项录入、核对并查看报告。可以就地新建运动员，开始录入前取消不会留下档案或空测试。开始录入后有效修改自动保存；刷新可以继续当前记录。输入错误或保存失败时不会显示完成。

测试方案保存有序项目组合与推荐评价方案。选用后可调整本次项目，记录保留采用时的方案快照；以后修改模板不会改动历史记录。年龄、体重、身高保存在每次测试中。

报告顶部选择队伍、运动员和测试记录，并提供“编辑本次数据”及“导出本次测试”。PDF 用于阅读，HTML 可独立打开和编辑，JSON 保存本次测试数据；三者均只导出当前记录。完整资料库使用 JSONL 备份。

运动员管理维护档案和历次记录；队伍管理维护成员、转队和移出。删除队伍只解除成员归属，不删除运动员或测试。

## 指标与评价标准

指标库按项目主能力分表，每个项目下列出全部指标。上方选择评价方案，只改变查看和编辑对象，不改变当前报告关联。标准修改先核对变更及影响数量；保存后关联历史记录同步重评，测量数据和手写解读保留，评价依据变化时标记解读待复核。

姓名、专项、年龄、体重、性别组成报告第一张信息卡，均取本次记录。重复统计仍需每指标至少三个有效值，删除了均值单元格的 n 标记；原始试次继续保留。

IMTP 峰值、相对峰值、各时间点力与 RFD 合并到一张结果表。只录入 RFD 时，换算力可用于有来源标识的曲线，不进入实测力结果和统计。最佳模式仍跟随峰值力代表试次；无峰值力的原始数据保留在明细。

时间点力可设置峰值百分比评价：同次 F(t)/PF×100；均值模式先逐次计算，再平均有效配对。RFD 仍以 N/s 设置标准。不预置任意时点等级，250 ms、90%不构成默认常模。旧100/200 ms的 N 标准保持，直到主动切换；切换不自动换算原阈值。条件失配、缺峰值或时点力超过峰值时不做正常分级。

训练速度表完整显示 MAS/VIFT 百分比，有对应有效成绩时附个人速度。保留速度图、MSS、SRR及做功休息配对；RST生理目标保持④⑤。

## 数据兼容

资料库 schema 3、记录 schema 2 保持。新增测试方案存于配置，可选的测试方案快照存于记录；IMTP 时点标准存于共用方案。完整 JSONL、单报告 JSON 和独立 HTML 保留新字段与生效标准。导入同编号不同内容的方案会创建新编号，并重映射导入记录。

旧版兼容 JSON 保留旧版能够表达的实测数据和评价，不包含新测试方案及百分比时点规则；不会把百分比阈值写成牛顿标准。回退前请另存完整 JSONL 备份。
