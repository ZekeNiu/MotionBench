# MotionBench 2.14.0

本版将跳跃 FVP 和垂直跳表现响应放在“能力结构分析”最前面，沿用桌面左图右表的布局。原有四类分析保留全部结果，采用更紧凑的两列排布。

## 录入跳跃剖面

在本次项目中选择“SJ FVP”或“CMJ FVP”，填写本次体重、测量设备、测高方法、起始姿势或目标蹲深，以及蹬伸距离和来源。按附加负荷记录跳跃高度，自重跳填写 0 kg。至少需要三个不同负荷，建议使用四至五个负荷；同负荷可以重复测量。单次实测蹬伸距离覆盖统一距离。

每个负荷取最高有效高度对应的完整试次，原始试次保留；同负荷至少三次有效测量时显示均值 ± 样本 SD 和 CV。可排除试次并填写原因。单人、多人手动录入与 MotionBench Excel 模板使用相同字段。

## 查看图表与情景

FVP 可独立选择 FV、PV、实测点、最优剖面、另一方向对照和 95% 置信带。FV 与 PV 同时显示时共用速度横轴，力读取左轴，功率读取右轴。切换 90° 垂直或 30° 倾斜目标后，显示对应的最优剖面、imbalance 和发展方向。悬停或聚焦负荷点和明细表可查看对应结果，点击或 Enter 固定选择，Escape 取消。

表现响应面板分别显示仅改变 F₀、仅改变 V₀ 后的垂直跳高度变化。输入两个参数的改变百分比进行即时预览，提交后保存；也可使用 +5% 快捷情景。指标表显示当前值、情景值及简洁判定。

PDF 根据导出瞬间的报告生成，包含已有结果的 SJ 和 CMJ 剖面及各自保存的图形选项，原始试次进入附录。

## 计算方法与来源

经典剖面采用 Samozino–Morin 的平均推进速度法。高度和距离以米计算，力和功率同时提供按运动员体重归一化的参数。每个负荷代表点计算平均力和速度，再以 OLS 拟合 F–V 直线；P–V 曲线由同一模型相乘得到。95% 置信带为实测速度范围内的回归均值区间。

目标最优剖面在当前 Pmax 和无负荷蹬伸距离下，使用目标角度的重力分量求解。Imbalance 为 |1 − S/Sopt| × 100%；比值小于 1 对应发展力量端，大于 1 对应发展速度端，相等时发展整体功率。

Li 弹性框架内部采用 λ = 0.77；经典 V₀ 转换为 1.54 V₀ 后计算垂直跳高度及解析弹性，有限情景重新求解高度。Fₑ、vₑ 与 1 比较为超比例、等比例或次比例响应；ER 比较两端响应；EN 与当前情景前的值比较整体敏感度变化。判定使用未舍入值，相等采用相对容差 10⁻⁹。
