# MotionBench 2.24.0 纵向比较

在报告首页选择队伍和运动员后，打开“测试记录”并勾选多次测试。选择一条时显示单次报告；两条及以上自动显示纵向比较，按测试日期排列。同一天的记录通过标题和短编号区分。

## 查看变化

“代表成绩”仍可选择最佳值或均值。新组合默认使用最后一期的设置，各期统一采用最后一期关联的当前评价方案；各期年龄、体重和测试背景按当期信息计算。

原有图表增加日期系列。柱顶和实测点之间的连线表示相邻记录的实测变化；负荷速度、力时、乳酸、FVP 和弹性分析继续使用原数值坐标与模型。日期较多时，在模块内部横向查看图表和结果表。

结果表每行对应一个指标，各日期分别列出成绩、适用的试次统计与评价。“首末变化”比较第一期与最后一期，“近期变化”比较最后两期。只有两期时合并为一个变化栏。端点缺测或测量口径不一致时，该项变化留空。

- 40 → 44 cm：增加 4 cm，增加 10%。
- 10% → 15%：增加 5 个百分点。
- 评分保留分数变化；筛查等级显示如 2 → 3。

“损伤风险筛查”改为保留左右侧的部位雷达，红色 1 分、黄色 2 分、绿色 3 分。各期未测或未获评价的部位留空。FMS 仍单独保留七动作 0–3 分、疼痛、左右侧与备注。

“运动表现概览”叠加各期能力雷达。独立的能力结构分析继续展示各期训练方向、模型与参数。

## 编辑与解读

点击“编辑测试记录”，选择已勾选的一期，修改保存后返回原比较。解读正文按“运动员＋所选记录组合”独立保存；再次选择同一组合会恢复正文。数据或评价依据变化后，正文保留并提示复核。

单次报告与比较报告的“解读与干预建议”右上角均可直接点击 AI 图标。生成完成后打开可编辑草稿，点击应用替换正文并保留上一版。运行状态、取消、失败重试和草稿入口均位于解读区域。

## 保存与导出

程序自动保存所选记录组合、代表成绩和解读。重新打开后恢复原比较。

沿用原导出菜单：PDF 输出完整比较报告；可编辑 HTML 与 JSON 保存所选记录及评价方案、图样和计算设置，重新打开可复现结果。日期较多时，PDF 将图表与日期表分段排版并重复必要标题、表头和图例。

完整 JSONL 备份包含比较正文。合并资料库时，已有正文保留，发生冲突的导入正文作为导入版本保存。
