# MotionBench 2.22.0 使用说明

Windows 桌面版版本为 **2.22.0-desktop.1**，共享离线工作台版本为 **2.22.0**。

## 为通用项目选择报告图表

打开“项目与指标库”，选中通用项目，进入“编辑项目设置”的“报告图表”区域。

1. 勾选“在报告中显示可视化图”。
2. 选择图表类型，并勾选展示指标。使用上下箭头调整指标顺序。
3. 查看图样预览，再保存项目设置。预览使用示例数据，报告使用该次测试的测量结果。

| 图表 | 适合查看的内容 |
| --- | --- |
| 横向条形图 | 当前报告采用的代表结果，尤其适合较长的指标名称 |
| 纵向柱状图 | 同单位指标的代表结果 |
| 试次点图 | 各次实测值及重复测量的波动 |
| X–Y 散点图 | 同一次试次中两个指标的配对关系，需选择不同的 X、Y 试次指标 |
| 目标对比图 | 实测结果与该次评价方案适用的目标 |
| 评分雷达图 | 3–8 项指标按该次评价方案已有明确规则得到的单项分数 |

报告在左侧展示图表，右侧保留完整结果表。不同单位的原值分别绘图。关闭“在报告中显示可视化图”后，报告使用表格。

图表设置由项目统一管理。修改后，测量定义兼容的已有报告也采用新图样。测量方法、单位或录入层级不同的历史记录继续使用其兼容图样或表格。

目标和评分来自每条记录采用的评价方案。缺少有效测量或适用规则时，报告说明具体原因，完整结果表继续保留。雷达评分规则在评价方案中维护。

## 报告与导出

“运动表现概览”保留能力图和评分，移除了“查看能力评分的计算”折叠明细。评价方案中的计分编辑与预览继续可用。

导出的 HTML、JSON 和 PDF 保留导出时的有效图样；以后修改项目设置不会改变已经导出的文件。完整 JSONL 备份保存项目图表设置。

本轮为本机交付，安装程序名称为 `MotionBench-2.22.0-desktop.1-Setup-x64.exe`。验收范围与成品校验见[验收记录](acceptance-2.22.0.md)。
