# MotionBench 2.19.0 验收与迁移说明

本版以已发布的 2.18.0-local 为基线，保留单人／多人四步录入、跳跃与冲刺 FVP、弹性分析、原始测量及手写解读。D 盘工作区是正式源码，日常入口为 `MotionBench.html`。

## 本次交付

- 测试记录、队伍和运动员按当前对象组织操作；常用筛选直接显示，更多条件与操作按需展开，批量操作只在选中后出现。
- 指标库负责测量定义、代表试次和协议；评价方案按项目设置目标、等级、参考及能力汇总，保留完整发布历史。
- 网页与 Excel 使用统一采集合同。FVP 参数回到项目页，IMTP 时间点合并到同一张表，Hop 新录入仅保留整次结果，历史逐跳资料只读保留。
- 能力平均分采用固定成员及显式评分转换；缺项时不缩小分母，颜色只使用已配置的汇总分级。报告、AI 输入及导出使用相同结果。
- 管理保存经候选校验及事务提交。失败保留原资料，旧页面不能覆盖另一页面刚保存的内容。

## 迁移行为

第一次打开新版时保留升级前原始资料，再切换到升级后的资料库。测量和解读保持原值；已能确定的代表试次规则按正确规则重算，差异进入可下载的迁移核对清单。不确定的旧规则标为待核对，不补造标准数值。

旧“最低达成”停用；旧平均配置固定明确成员，无法确定的计分转换等待用户补齐。历史 Hop 逐跳记录保留身份和原算法，不会被整次补录覆盖。旧 IMTP 指标身份及任意已有时点继续可读。单条记录导出携带完整评价方案；合并导入遇到相同编号但版本或发布历史不同的方案，保留独立副本并关联相应记录。

## 回退

程序回退标签为 `rollback-v2.18.0-local-before-management-20261011`，提交 `0faaa5c1dfb9ee234faf30b751067670fdf4d9ff`。固定标签已上传 GitHub，旧成品哈希已核验。

1. 在新版“备份与恢复”导出当前完整备份和升级前原始资料。
2. 关闭其他 MotionBench 页面，选择“恢复升级前资料并结束页面”。
3. 将固定标签中的旧程序放回原路径，使用原浏览器、原地址打开。
4. 核对运动员、测试记录及手写解读。再次升级后，可用“导出回退前新版资料”找回最近一次回退前的新资料，并合并导入。

只替换旧 HTML 不会回退浏览器中的资料结构。详细操作见 `motionbench-2.19.0.md`。
