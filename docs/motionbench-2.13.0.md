# MotionBench 2.13.0

2026-10-08。本版增加离线 Excel 模板与导入，统一测试方案的项目勾选，扩充等长力量选测方向，并整理报告顶部的人员与记录选择。

## 使用变化

- 在数据录入中选择已有运动员、日期和项目后下载 `.xlsx`；多人模式可按队伍选择名单。已有记录可下载包含原始测量的补录模板。
- 导入前按运动员与项目核对；有数据默认保留，明确选择后才替换整组试次。空白项目不清除旧数据，同模板重导不重复建记录。DSI 共用设置的差异单独列出、默认保留；测量协议与单位变化随项目显示。任何错误或保存失败均不写入半批数据。
- 测试方案、创建记录和修改本次项目共用分组勾选；常用方案另有已选项目排序区。临时勾选不改写常用方案，取消选择保留原始测量。
- 等长力量支持10个部位组、42个方向条目，包括肩水平运动、肩胛、肘、前臂、腕、躯干及膝胫骨旋转。颈与躯干区分运动方向，四肢区分受测侧。新增方向的评价目标留空，按实际协议配置。
- 报告顶栏按队伍、可搜索运动员、测试记录与编辑/导出排列。搜索只筛选候选项；队伍排除当前人员时清空报告；连续快速切换只接受最新选择。

## 数据与回退

两个既有HTML文件名继续生成相同内容，离线模板库内嵌在文件中，无需连接Excel云服务或上传运动员数据。ExcelJS4.4.0及MIT许可随包提供。模板默认适用于每批1–300名已有运动员，单文件不超过25MB。

2.12.0基线提交为3e12b74，HTML SHA256为552492e51f69be2b87b09bdb017cc99fe3284163ea5d1edba51d35f1f099e95b。[下载回退版本](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.12.0)。代码回退不等同于本机资料库回退；请保留升级前完整备份。旧版兼容导出对选测方向作有效投影，遇到旧版不支持的新部位时明确拒绝该兼容格式，原始数据保留。

## 方向依据

方向分类参考[OpenStax解剖学教材](https://openstax.org/books/anatomy-and-physiology-2e/pages/9-5-types-of-body-movements)。肩胛上提、下压、前伸和后缩参考[Garner与Shim等长测力研究](https://pubmed.ncbi.nlm.nih.gov/17986391/)。方向可记录不表示跨姿势、设备或人群的测量可直接比较；本版未添加未经配置的力量目标或配对正常范围。
