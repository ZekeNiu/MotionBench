# MotionBench 2.26.0：横向比较与群体报告

在报告首页选择运动员，展开姓名后勾选真实测试日期。一人选择一条记录打开个人报告；一人选择多条打开纵向比较；多人各选一条打开横向比较。加入第二人时，已有多日期选择保留，指定本次比较的一条记录后再生成；移除第二人可恢复先前的纵向选择。

群体参照在首页的独立分区配置。选择成员条件、统计日期和每人取样方式，可以将群体加入个人比较，也可以只保留群体查看群体报告。日期范围在保存时固定；重新打开报告不重新取样。“更新参照数据”会按保存条件重新计算。

每人取样支持最近可比测试、期间最佳成绩、期间均值。期间均值先平均每个人的有效测试，再对人等权平均。各指标独立显示人数，可展开查看实际来源记录。关节平衡、双侧差异等先在每条真实测试内计算，再汇总。群体最佳在期间均值模式下表示最佳个人期间均值。

群体结果汇总后，使用共同适用标准评价。遇到不同年龄或体重条件导致的标准差异，在群体设置中明确选择统一目标或区间后保存。FMS 汇总允许小数，原始动作录入仍遵守整数评分规则。

报告标题下可以调整“报告重点”和“比较基准”。重点决定资料、摘要、排序和新解读的关注对象；基准决定差值。没有基准时显示基本信息和测试日期两张摘要卡；选择基准后增加相对优势、相对不足。切换呈现不改变样本或人工正文。

“专项分类”与“年龄分组”是独立管理页。专项细分在所属专项内部维护；年龄区间可以在群体条件中与专项组合使用。既有分类编号及历史归属保留。

已保存的横向、群体报告位于“测试记录 → 已保存报告”。PDF 和直接打印使用当前群体、重点、基准、图表系列、正文及展开内容；宽表按可用宽度拆列，保留可读字号和必要表头。

本地构建与验证范围见 [2.26.0 验收记录](acceptance-2.26.0.md)。
