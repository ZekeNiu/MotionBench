# MotionBench 2.28.0 使用说明

## 创建团队报告

在报告选择区点击“团队报告”，选择已有队伍，再按需增减本次报告的成员。此选择不会改变运动员档案中的队伍归属。

填写测试日期范围后，每人预选范围内最近的一条记录；同日有多条记录时需指定其中一条。也可以手动改选范围内的其他记录。一个人的所有项目均来自这条记录，缺少的项目不会从其他日期补齐。范围内没有测试记录的成员仍保留在报告中。

代表结果可选“最佳”或“均值”，评价方案可统一选择，也可不使用评价方案。

## 项目图表和数据表

各项目采用上图下表。默认柱状图按成绩优劣排列：跳跃高度等越大越好的指标降序，用时等越小越好的指标升序；没有明确优劣方向的指标仅按数值排序。相同成绩共享名次，后续名次跳号。

图形可切换为排名点图、箱线图叠加个人点、直方图。每次只展示一个指标，下方表格始终保留每人的全部指标代表结果。缺测显示横线，不作为零参与排名或分布。不同测量条件的结果分别展示。

箱线图使用线性插值四分位数（Type 7），箱须落在四分位距1.5倍范围内最远的实际结果；箱须外的个人点仍保留。少于3个有效结果时仅显示个人点。直方图采用Sturges等宽分组，区间人数总和等于有效人数。等级和类别指标仅提供适合其数据含义的图形。

## 运动表现和筛查概览

运动表现雷达先按统一评价方案计算每个人的有效能力分数，再求各维度的全队平均；每个维度显示实际参与统计的人数。可以搜索并叠加最多3名运动员。团队概览不显示训练方向。

筛查雷达显示各部位出现黄色关注或红色预警的独立人数。左右侧合并，同一人同一部位出现多条提示只计一人。悬停或点击可查看人员、侧别、等级和具体测试依据；未定位到部位的提示另列。未测或缺少适用评价与已测但无人需要关注分别显示。

## 保存、更新和导出

团队报告保存当时的人员、测试数据、评价方案、图形选择和独立正文。重新打开不会自动改变已保存结果；“更新已选记录数据”重新读取原先指定的记录。更换人员或日期，在报告设置中调整。

已保存团队报告位于“测试记录”的报告列表，支持HTML、JSON、完整备份和PDF。PDF保留全部人员及指标，宽表分段并重复人员信息，筛查人员名单以静态内容保留。

## 升级与回退

本版本增加团队报告存储，新版可读取旧备份。回退程序时应同时恢复与旧版配套的升级前资料目录副本；仅替换程序不能降低已经升级的数据库版本。升级后新增的资料应另存完整备份。
