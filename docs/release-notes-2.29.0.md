# MotionBench 2.29.0

侧栏“日常使用”统一提供“测试报告”入口。按“报告类型 → 分析方式与对象 → 测试记录 → 核对并查看报告”完成选择；个人与团队报告都支持单次报告、横向比较和纵向比较。各步直接展开内容，返回上一步保留选择，取消后回到原报告。

单次团队报告的摘要显示报告人数、筛查关注人数、主要关注部位和相对薄弱能力。主要关注部位依据筛查关注人数，相对薄弱能力依据已有能力评价均分；没有足够评价结果时显示“待评价”或“暂无法比较”。表格第一列去除单独底色，与其他报告保持一致。

团队纵向比较使用固定成员名单和所选测试日期，缺测保留为空。同日存在多条记录时明确选择来源；趋势按实际日期间距展示，各日期团队均值与同一成员配对变化分别呈现。

团队横向比较支持已有队伍、当前自选成员组和参考群体，也可仅比较参考群体。报告重点和比较基准可分别设置。参考群体沿用个人横向比较的筛选、最近可比测试、期间最佳、期间均值及共同评价标准设置。

团队测试记录未设置起止日期时显示全部历史记录；只设置一端日期时按该端筛选。日期调整后保留仍有效的原选择。

报告默认名称为“损伤风险筛查与运动表现测试报告”，可在核对步骤修改，记录名称独立保留。移除报告主标题和各一级标题下的说明小字；编辑数据和导出操作改为主标题右侧的小图标，取消独立顶部操作栏和“已保存到本机”文字。

比较报告编辑数据时可选择具体来源记录，完成后返回原报告并刷新相关结果；已有报告的解读与显示设置保留。
