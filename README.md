# MotionBench

跨项目的运动表现评估与训练建议工作台。当前版本 **2.16.0**。录入、计算、图表、备份与 PDF 导出均可离线使用。

![MotionBench](assets/motionbench-logo.svg)

### 打开与使用

- **离线评估**：双击 `MotionBench.html`，无需安装。直接打开 HTML 时，AI 服务需要允许浏览器跨域访问。
- **使用中转 AI 服务**：Windows 双击 `Start_MotionBench.cmd`，在自动打开的页面中使用；保持启动窗口开启。需要 Python 3.10 或更新版本。其他系统运行 `python3 scripts/serve.py`。
- **更新旧版**：`Ringside_Boxing_Assessment.html` 保留为内容相同的兼容入口。把新版放回原文件位置，用原浏览器打开，可继续访问该路径的记录。切换到新文件名、另一浏览器或本机启动入口前，请先在旧页面导出运动员库（2.8.0 使用“备份与恢复”），再导入新入口；不同页面地址的浏览器数据不会自动合并。
- 下载后的两个 HTML 均可独立工作。无需使用 GitHub 网站上传测试数据。

### 迁移与回退

在原路径、原浏览器打开新版时，会先校验旧资料并写入新资料库；成功后切换，旧浏览器存储继续保留。“备份与恢复”可下载迁移前资料、导出完整备份或恢复上次导入前资料库。导入校验失败不替换现有资料。

回退到 v2.7.2 时使用迁移前备份；也可导出旧版兼容 JSON，保留已测试记录和旧版可表达的生效标准，但不包含队伍、空档案、回收站、测试方案和新增 IMTP 时点标准。分类在导出副本中转换为当时的显示名称，不保留独立分类编号及顺序快照；同名分类附编号区分。VIFT 方法文本保留，旧版不提供独立编辑入口。峰值百分比不会写成 N 标准。不要把新版完整 JSONL 直接交给旧应用。

### 两种建议有什么区别

| 入口 | 用途 | 使用方式 |
|---|---|---|
| 生成离线摘要 | 按规则整理测试发现和基础建议，作为手写解读的起点 | 无需联网或密钥 |
| 生成 AI 综合建议 | 综合指标关系、专项、训练背景和周安排，生成有剂量、取舍、进阶条件的教练建议 | 需要 AI 服务、文本模型和可用额度 |

AI 建议以最多两页 A4 为目标，生成后使用实际打印样式预检；超长时自动精简一次，保留动作剂量和关键调整条件。正文集中于本次训练需要，不加入泛泛免责声明。

点击“应用草稿”才更新正文，并保留上一版。AI 状态与已等待时间仅在解读编辑页和 AI 设置页显示，可取消等待或重试。生成期间可继续查看同一次测试，完成后返回解读页主动查看草稿；始终留在解读页且没有其他对话框时，会自动打开预览。切换运动员或测试记录会清除旧任务，未完成或过时的结果不会替换正文。

### AI 设置与密钥

在侧栏“AI 服务”填写 HTTPS API 基础地址、密钥和模型，点击“保存设置”。本机入口先保存，再读取可用模型；切换模型后再次保存。不同服务的模型名称并不通用。读取模型成功后，实际生成仍可能受额度、模型权限或响应速度影响。“参考资料与方法”有独立入口。

Windows 本机启动入口使用当前账户的 DPAPI 加密，将地址、模型和密钥保存在项目目录外的 `%LOCALAPPDATA%\MotionBench\ai-settings.dat`。保存成功后输入框清空；重开浏览器或启动器无需重新填写。同一地址修改模型可沿用密钥，更换服务地址必须填写新密钥。“忘记密钥”删除已保存密钥。页面只读取保存状态，不读回明文。

密钥不进入源码、浏览器存储、导出 HTML、运动员资料、备份或 PDF。本机服务只监听 `127.0.0.1`，检查页面来源和连接令牌，由服务端读取凭据转发请求；不记录请求内容。AI 会收到当前测试与训练背景，不发送姓名字段或其他运动员记录；自由备注请自行去除身份信息。导出 HTML 移除本机连接令牌，仍可独立打开。直接双击 HTML 时，AI 密钥仅临时保存在当前页面，刷新后需重新输入；当前账户加密保存需要 Windows 启动入口。

如果模型列表可读、聊天接口可调用，但直接打开 HTML 仍报网络错误，服务可能拒绝浏览器预检。请使用本机启动入口；修改密钥或关闭浏览器安全保护不能修复服务端预检。

## 跳跃 FVP 与表现响应

选择独立的 SJ FVP / CMJ FVP 项目，录入至少三个不同负荷的高度和蹬伸距离。“能力结构分析”先显示左图右表的 FVP 与表现响应，再显示原有四类分析。FV、PV 可独立显示；90° / 30° 目标对应各自的最优剖面、FVP的不平衡性和发展方向。响应图可分别勾选仅 F₀、仅 V₀、两端同时变化；联合曲线的 x% 表示两端各改变 x%。两个协议分别保存选择，导出 HTML 和 PDF 保留。参数情景输入继续支持两端不同的增幅。

弹性范数 EN 为 √(Fₑ²+vₑ²)；两端各提高 1% 的局部高度变化另以 Fₑ+vₑ 显示。有限增幅使用模型完整重算。概览按 SJ FVP、SJ 弹性、CMJ FVP、CMJ 弹性、EUR、DSI、SRR 排列有效结果，先给方向，再给数据。

## Excel 录入

第一步“选择运动员”可勾选一名或多名已建档人员，第二步“设置本次测试”填写共同日期并选择项目。第三步“按项目录入”提供独立的“下载 Excel 模板”和“导入 Excel 文件”按钮，也可切换运动员手动录入。模板只包含本次所选项目与等长方向，下载不会创建空测试记录。

填写 `.xlsx` 后导入，核对姓名、编号、日期和项目。已有数据默认保留，需要更新时逐项选择“替换为 Excel”；替换采用整组测量，不追加重复试次。空白项目不清除旧值，等长力量只替换模板选中方向。再次导入同一模板不会重复创建记录；另一轮测试请重新开始数据录入，生成新的目标记录。

“编辑本次数据”的按项目录入页面使用同样两个独立入口，可下载含已有测量的补录模板。可变测量工作表使用 Excel Table，LVP 每人预留15行、FVP30行，补录模板在已有数据后追加相同数量空行。普通试次可留空试次编号，由导入时分配；手填重复编号会拒绝。Hop 与 IMTP 的关联编号需明确填写。单人新增行可省略身份；多人请从“运动员／测试”下拉选择，已有身份冲突会拒绝。旧模板仍可导入。未测留空，真实零填0，公式请粘贴为值。日期、身体资料和共用 DSI 设置的差异单独确认，默认保留。导入有错误或保存失败时，整批不写入。

本次临时录入可在同一页面刷新恢复；离开录入后，已保存测量仍保留，未测空草稿不入库。新建档案在首次保存测量时一并保存，Excel 仅使用已建档运动员。

升级前请导出完整备份。2.16.0 的远程回退点为 `rollback-v2.15.0-20261009`，回退时使用升级前完整备份恢复对应资料。肩、髋平衡会一次性迁移为 ER:IR，区间倒数并交换边界；无法转换的规则保留副本并停用，管理中心显示核对提示。所有非示例评价方案的空白等长目标补入已确认文献参考，手填目标优先；之后主动清空或修改的参考不会自动补回。只替换旧版 HTML 不能撤销已完成的资料迁移。

等长参考按性别、年龄、身体资料和文献侧别生效，可在共用评价方案中编辑。来源未覆盖的方向留空，无法将参考力换算到 Nm 时不生成目标。单一力量参考值采用黄色“关注”和绿色“达标”；有分级区间时沿用原有评价。疼痛和双侧差异继续独立评价。数据源及方法见本版说明。

人体图只显示有实际测试记录部位的圆圈；零值、疼痛和部分已录入结果保留，未测部位不再显示占位圆圈。

## 运动员档案与本次背景

全新资料库直接提供一名“示例”运动员及独立的模拟评价方案；可像普通运动员一样编辑或删除，删除后不会自动补回。已有资料库和恢复内容保持原样。

新建／编辑档案填写姓名或编号、队伍、性别、生日及专项；惯用手、运动水平、抗阻训练年限与相关既往伤病在可选展开区。有生日时，按测试日期自动计算周岁，年龄不可直接修改；没有生日可手填年龄。修改生日会一次重算全部历史记录，包含归档和回收站；清除生日保留现有年龄。

“设置本次测试”和“本次背景”填写当前身体资料、症状及训练限制、上一场和下一场比赛日期。多人共用日期与项目，但每人的年龄和背景分别填写。每次新测试的症状、比赛、周期及说明默认留空；器械和周安排需主动点击“沿用上次训练安排”。AI 接收本次年龄、伤病及训练背景和以测试日期计算的比赛间隔，不发送原始生日。

## 评估功能

- 固定侧栏进入数据录入、人员与测试管理；报告顶部选择运动员与记录、编辑本次数据和导出。数据录入按选人、设置测试、逐项录入、核对报告四步完成。
- 支持独立运动员与队伍管理、搜索分页、队伍筛选、批量分组或更换方案、归档和回收站。可复用测试方案保存项目顺序和推荐评价方案；历史记录保留采用时的快照。专项和惯用手分别填写。
- 共用评价方案更新后，关联的历史记录自动使用最新标准；测量条件不匹配时保留实测值。现有解读保留，并在评价依据变化时标记待复核。
- FMS、等长力量、CMJ/SJ/DJ、10/5 Hop Test、CMRJ、IMTP、负荷-速度、MAS/MSS、30-15VIFT、乳酸等测试与报告。指标库统一编辑能力分类、项目、指标及所选评价方案标准；分类改名、排序与项目调组只影响后续测试。IMTP时间点力支持同次峰值百分比评价，RFD保持N/s。
- 跳跃组合图以钢蓝柱表示垂直跳跃高度（cm），深青圆点表示 RSI（m/s）。Hop 支持设备汇总或逐跳录入，报告附录每次完整测试一行，原始单跳仍完整保存。RSI 与 RSI-modified 使用已配置的独立分级标准；设备 Active Stiffness 可按 N/m 或 kN/m 录入。
- “能力结构分析”按力量发展方向、反应力量水平、速度耐力发展方向、心肺发展方向分组；卡内对齐实测结果与判定，速度耐力和心肺先显示发展方向。有效结果独立保留，无数据的指标和卡片自动隐藏。iDSI 使用实测冲量及明确时间窗；DJ/Hop FT/CT 反应比独立计算，ASR 仅列数据，SRR 给出参考类型。
- CPET 保存原报告的 VO₂max／VO₂peak、VT／LT 名称、摄氧量、心率和 RER。定义库内置 FRIEND 2022 成人分层参考表，可按年龄、性别、跑台／功率车匹配并编辑。常模等级与专项目标分别设置，心肺发展方向根据摄氧量和第二阈值占比两项目标判断。
- 同条件重复试次按最佳或均值汇总；至少 3 个有效值显示均值、样本 SD 与适用时的 CV。缺测不当成零。IMTP最佳值仍跟随峰值力代表试次；百分比均值先逐次归一，实测与换算来源分开。
- 等长力量按部位勾选本次方向，覆盖颈、躯干、肩、肩胛带、肘、前臂、腕、髋、膝、踝足，共42个方向条目；旧记录保留原方向。3–8个部位使用雷达，其余使用横向百分比图，未设目标保持空白。桌面维持左图右表，重复统计保留在原表；手机和PDF按实际空间排版。
- 等长力量评价与关节平衡采用“达标／关注／严重”短标签；未设标准的平衡比值显示灰底。悬停可查看完整原因，数值与侧别保留，常规表格与 CMJ、IMTP 对齐。
- 人体部位圆圈支持鼠标悬停、键盘聚焦和手机点击，列出当前最佳／均值模式下相关测试的侧别、实测值、评价、疼痛和缺测。绿色状态显示“优秀”，原评价和优势统计规则保持。
- 训练速度参考分别显示 MAS 和 VIFT 百分比及个人速度；30-15VIFT 测试方法独立填写。训练表列出主动／被动恢复及成对时长示例，RST 增加 5／15 秒与 5／30 秒被动恢复。
- 完整资料库使用分批处理的 `.motionbench.jsonl` 备份；继续接受旧 JSON。单报告 HTML／JSON 和离线 A4 PDF 保留导出时的评价内容。
- 数据按运动员、记录、队伍和评价方案保存在本机 IndexedDB；列表只读取摘要，打开记录时再读取测量数据。

更换专项时，请核对本次评价标准、协议和适用人群。部分内置测试与参考原用于拳击，品牌更名不会自动把这些标准变成跨项目通用常模。原始方向、单位、公式、历史记录和导入结构继续兼容。

页面与 PDF 采用统一的银灰样式，数据行白底。低矮窗口的侧栏可整体滚动，顶部关闭按钮保持可见；重新打开时会显示当前导航项。

```powershell
python scripts/build.py
npm ci
npm test
npm run test:refinement
npm run test:catalog
npm run test:report-v210
npm run test:imtp-layout-v210
npm run test:management

python scripts/review_pdf.py --manifest=management-download-verification.json --output=management-render-verification.json --focused
```
