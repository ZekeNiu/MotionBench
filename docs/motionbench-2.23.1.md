# MotionBench 2.23.1 个人纵向分析

在报告首页选择队伍和一名运动员，再勾选多个测试日期。选择一个日期时显示原个人报告，选择多个日期时显示个人纵向分析。同日有多条记录时，指定本次采用的记录。

损伤风险筛查使用一张身体部位雷达图，每个测试日期一条线：绿色3分、黄色2分、红色1分，未判定留空。点击日期图例可突出对应日期；点击部位或数据点可查看该次记录的原项目、侧别、疼痛与备注。

运动表现概览展示各期能力图和能力数值。独立的训练方向区显示各日期的个人判断、相关参数及方向变化。

项目区采用上图下表，可选择指标、切换原图对照与指标趋势，并查看结果或记录明细。原图保留每期的实测坐标、试次及个人拟合；不同单位、侧别和协议分别展示。缺测保留具体原因，已有日期的有效结果继续显示。

最早选中日期作为基线，变化量为本期减基线，保留真实正负号。有明确评价依据时才标示改善或下降，其他指标显示增加、减少或持平。适用变化率以正基线计算；百分数指标显示百分点。三个以上不同日期按实际时间间隔绘制描述性线性趋势，并给出原单位每30天的斜率。

FMS原动作雷达图使用0、1、2、3分刻度；0分保留在中心，缺测留空。原始左右侧、疼痛和备注仍可查看。

连续小值保留三位有效数字或科学计数；仅在实际数值尺度的机器精度范围内处理运算舍入残差。原始测量不因显示或比较计算而改写。

个人纵向正文独立保存，支持手工编辑、离线摘要及已有AI服务。数据或判断依据变化后保留原正文并提示复核；编辑原记录后可返回此前的日期选择。

纵向AI输入沿用个人报告的姓名与原始生日字段去除规则，保留年龄、测量、训练背景及判断依据。本机档案和导出报告保留正常身份显示。

PDF跟随当前指标、图型、表格页签、折叠状态和正文，并完整分页。HTML可独立切换和编辑；JSON保留该运动员所选原始记录、评价依据、个人变化及趋势结果。完整资料库备份保留原有记录和正文。
