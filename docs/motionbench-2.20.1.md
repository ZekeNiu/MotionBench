# MotionBench 2.20.1 修订说明

本次修订版本为 Windows **2.20.1-desktop.1** 与离线 HTML **2.20.1**。分页修订已实现，公开发布与本机最终交付验收尚未完成。

2.20.0 发布后的本机补验发现：多轴能力雷达图与三张评分明细表合为一个过高卡片，PDF 导出触发超页保护而中止，没有生成 PDF。原目录安装、版本与资料对照已通过，未发现资料改变。已公开的 2.20.0 程序和历史验收保持不变，详细记录见 [公开发布与补验](publication-2.20.0.md)。

本次修订让过高卡片按图表与表格的内容分段输出，标题与其后的内容一起排版，较短卡片保持完整；能力评分、等级与原始测量的计算不变。追加多轴与长表合成复现，核对代表指标、固定成员平均以及各评分明细的内容和分页，具体通过范围由新成品的验收证据确认。

HTML、Windows 程序、实际 PDF 与模拟演示按新成品重新核验，随后部署并检查真实网址。新的成品校验值、验收文件与公开下载将在正式发布时提供；本机原资料的最终 PDF 复验仍待完成，2.20.0 的旧成品与通过记录不能替代这些结果。

正式发布后，可在安装版“应用设置 → 更新与版本”更新，或运行新 Setup；便携版退出后替换程序文件。程序更新与资料恢复分开处理，重要测试批次仍应另存完整 JSONL 备份。

预备发行入口：[Windows 2.20.1-desktop.1](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.20.1-desktop.1)、[HTML 2.20.1](https://github.com/ZekeNiu/MotionBench/releases/tag/v2.20.1)，在正式发布后生效。安装、迁移与更新操作见 [Windows 桌面版](windows-desktop.md)。
