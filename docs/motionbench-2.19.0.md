# MotionBench 2.19.0

本版统一了测试采集、Excel 和评价方案，并调整了测试记录、队伍、运动员及指标库的管理方式。日常入口仍是 `MotionBench.html`，单人和多人测试仍使用原四步流程。

## 管理与录入

测试记录保留常用筛选，其他条件收在“筛选”中；已应用的条件可以直接移除。选中对象后才显示批量操作。运动员姓名进入个人记录，队伍进入成员列表；可选择一人或多人开始测试。

指标库按能力分类选择项目，再查看字段和输出结果。它管理测量单位、代表试次和采集结构。评价目标、等级、参考数值及能力评分在共用评价方案中配置。修改目录用于后续测试，历史测试保留自己的测量定义。

## Excel

新模板将每个项目的测量参数与成绩放在同一个项目页。FVP 统一蹬伸距离在相应 FVP 项目页；填写逐次距离时优先使用逐次距离。导入前分别查看测量变化、参数变化和计算准备情况；可以只补充参数，空白参数及整项目空白保留原值。已有测量默认保留；主动选择“替换为 Excel”时，采用该项目在 Excel 中的整组测量，请保留需要继续使用的试次和字段。

IMTP 每次试次一行，时间点作为列显示。网页“管理时间点”可以增加时间，模板还会包含历史已有时间点。Excel 新增列标题须使用“125 ms 实测力 N”或“0–125 ms 平均RFD N/s”这样的格式。已有列按其原身份解释，请勿通过修改标题替换原时间点。

Hop 新增数据只填写整次结果，包括平均 RSI、平均高度、触地时间、腾空时间、平均 FT/CT、跳数、筛选依据、刚度和备注。平均 RSI 和平均 FT/CT 应填写设备给出的相应平均值。历史逐跳记录仍按原算法计算，可查看只读明细；整次补录不会替换历史逐跳组。

旧模板仍可导入。导入报错时，整批资料不写入；同一模板重复导入不会重复创建测试记录。

## 评价方案

打开方案后按项目选择结果，分别设置目标、等级区间和参考数值；年龄、性别等条件按需展开。新建方案从空白开始，也可以复制已有方案。发布会更新关联历史记录的评价，不改变原始测量或手写解读。

能力展示支持“代表指标”和“固定成员平均分”。代表指标缺测时，该能力不显示。平均分先选择固定成员，再逐项配置目标比例、评分表或评分点；所有成员均有效才计算。单项先转换为 0–100 分，再等权平均，成员缺测时不会临时减少分母。平均分的颜色来自它自己的汇总分级；未设置时为中性色。报告可展开查看成员成绩、换算得分和平均贡献。

原“最低达成”配置迁移后停用，需选择新的汇总方式。不能确定的旧平均评分规则保留待补齐，系统不会根据等级颜色猜测分数。旧标准数值和实际区间空档保持原样。

## 升级与回退

第一次打开新版时，程序在原浏览器资料库中保留升级前副本，再切换到升级后的资料。进入“备份与恢复”可导出当前完整备份、升级前原始资料和迁移核对清单。

本次程序回退点：GitHub 标签 `rollback-v2.18.0-local-before-management-20261011`，提交 `0faaa5c1dfb9ee234faf30b751067670fdf4d9ff`。旧 HTML 的 SHA256 为 `0a72a07e322f1c083b672e8647823977b3f1d11112b1d3bd7c65165de0c04741`。

同时回退程序与资料：

1. 在新版“备份与恢复”导出当前完整备份及升级前原始资料，另存到安全位置。
2. 关闭本项目的其他页面。在回退区域选择“恢复升级前资料并结束页面”，按页面提示完成后关闭当前页面。
3. 从上述固定标签或本地 `交付/MotionBench-2.18.0-local` 存档恢复原程序，保持原文件路径、原浏览器和原打开地址。
4. 打开旧程序，核对运动员数量、测试记录和手写解读。升级后新增的资料仍保存在新版完整备份中。

如果更换电脑、浏览器或页面地址，先在原入口导出资料，再导入对应版本。只替换旧 HTML 不会自动回退浏览器里的资料结构。已停用的 `Ringside_Boxing_Assessment.html` 根目录入口不再生成。

回退后再次打开新版，仍可从回退区域“导出回退前新版资料”取回最近一次回退前的新版副本，再通过合并导入恢复升级后新增的数据。合并遇到相同编号但配置或发布历史不同的方案，会保留导入副本及其记录关联。
