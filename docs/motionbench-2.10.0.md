# MotionBench 2.10.0

2026-10-07。本版基于2.9.0，完成指标库合并、报告布局、30-15VIFT与人体部位提示优化。本地交付包括正式源码、两个离线HTML入口和本版验收记录。

## 使用变化

- 侧栏只保留“指标库”。在同一页面按能力、项目、指标管理目录，编辑所选评价方案的标准；可新增、改名及排序能力，调整项目主分类、修改项目展示名、增补指标、启用或停用项目。分类修改用于后续测试，历史报告保留当时名称、顺序及归属。
- 侧栏分组增加分隔、留白与标题对比；选中项采用浅底、文字颜色及字重。1100px及以下使用抽屉。
- 等长力量、IMTP与其他结果表共用桌面分栏与表格边线。报告内容宽度达到760px时左图右表，重复统计保留在原表；更窄时上下排列。PDF中完整模块能放入一页则左右，过长则整个模块改为上图下表并续表。
- 人体图在桌面及PDF中放大，颈部圆圈与其他部位同尺寸。悬停、聚焦或点击圆圈可查看相关测试、侧别、实测值、单位、目标／评价、疼痛与缺测；较长内容可滚动。提示使用报告当前最佳／均值结果。绿色状态显示“优秀”，原评分与优势统计保持。
- “关注”卡片数字和单位使用同一关注色，零项仍为中性色。
- 30-15VIFT增加独立、可留空的测试方法。两种历史编号均可显示VIFT个人换算速度，原测量及标准关联保持；仅已知内置旧说明按精确别名兼容，自定义条件仍需匹配。
- 训练速度表补全MAS／VIFT个人速度、主动及被动恢复，最后一列为成对时长的“做功∶休息示例”。RST保留已确认的生理目标，增加5／15秒、5／30秒被动恢复示例。

## 数据兼容

完整备份保留有序能力分类、分类名称冲突、测试记录分类快照及独立VIFT方法。导入同编号不同分类名时默认保留本机，并可选择导入名称；同名不同编号保持独立。评价方案发布继续同步重评关联记录，目录名称变化不改写测量或评价。

单次JSON及可编辑HTML保留本次快照和冻结评价。旧版兼容JSON仅在导出副本中将分类编号转换为当时显示名，同名分类附编号区分，保留独立能力汇总；它不提供新版分类编号／顺序快照、测试方案、IMTP时点新标准及人员管理功能。VIFT方法原文保留，旧版没有独立方法编辑入口。

继续使用原路径、原浏览器可访问该入口已有资料；两个HTML文件内容相同，但浏览器按页面路径分别存储资料。切换入口前通过“备份与恢复”导出完整备份。
