# MotionBench 2.24.3 纵向比较完善

本次按个人报告逐项核对纵向比较的内容和评价显示，并改善多日期排版。个人报告的计算与布局保持现状。

## 已确认的问题与处理

- 纵向页额外列出了“各区域筛查等级”：移除该表，保留首页筛查雷达和原测试结果。
- 每个日期、项目各占一个原始试次入口：合并为每个模块一个“展开所有原始试次数据”，内部保留全部日期、项目和试次；PDF保留原始数据附录。
- 多日期矩阵挤占图表宽度：纵向测试模块统一上图下表。速度与储备按实际指标横向分图，保持原单位、坐标含义及ASR关系。
- 关节平衡与评价不清晰：等长力量按力量结果、双侧差异、关节平衡分组；对应日期结果单元格沿用个人报告的状态底色、短词和评价依据，不另造阈值。无标准或缺测继续说明原原因。
- 能力结构日期内容过于纵长：两期两列、三期三列、四期两列两行，更多日期响应排布；打印按行分组分页。
- 能力及FVP分析不完整：保留全部可用参数、组成、目标、结论、代表负荷点、拟合信息、模型条件、情景与方法说明。共用日期叠加图和比较矩阵之外，按期补充原报告的非重复分析内容。

历史和当前目录均包含乳酸、CPET、跳跃FVP（SJ／CMJ）和冲刺FVP。弹性框架由相应FVP数据派生，历史上即非独立录入项目。用户已确认缺失指纵向报告，因此本次不修改项目注册表和目录。
